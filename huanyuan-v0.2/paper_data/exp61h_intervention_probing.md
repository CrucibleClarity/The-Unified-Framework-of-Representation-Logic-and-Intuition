# 干预式探测方法论：干扰 token 分离直觉与结构 (EXP-61h, 用户设计)

> 日期: 2026-08-11 | 用户确立 | 可复用方法 (不限于本实验)
> 用途: 当直觉路径 (编译权重) 难以直接剥离时, 通过**干扰 token** 反向探测
> 直觉与结构在内部表示中的分布差异。

## 核心思想

直觉是编译的快速路径 (权重), 结构是语法/定义驱动的路径。两者交织,
难以直接分离。**干预法**: 引入干扰 token, 观察直觉与结构的响应差异,
反向显影内部表示。

## 设计 (用户原话)

**将 op 拆成两个相同的 token** (如 logical_and → logical_and_a / logical_and_b,
语义相同但 token 不同):

- **假设 1**: 直觉 (编译权重) 会**均匀分布**在两个 token 上
  (权重对两个同义 token 对称, 注意力均分);
- **假设 2**: 结构 (语法/构造路径) 会**尝试集中**在一个 token 上
  (语法要求确定位置, 收敛到一个 canonical token);
- **反向验证**: 拿这几个 token 单独做推理, 看推理效果 —
  若直觉均匀分布, 单 token 推理应保留部分能力;
  若结构集中, 单 token 推理应保留主要能力。

**拆得越多语法越乱**: 干扰强度可调 (拆 2/3/4 个 token), 拆越多语法歧义越大,
观察直觉/结构响应随干扰强度的变化。

## 可观察指标

| 指标 | 直觉 (预期) | 结构 (预期) |
|---|---|---|
| 注意力分布 | 均匀分布于同义 token 组 | 集中于单一 canonical token |
| 梯度/权重 | 对称 (同义 token 权重相近) | 偏斜 (一 token 主导) |
| 单 token 推理 | 保留部分能力 (组内任意) | 保留主要能力 (canonical) |
| 判定口径 (OOD) | 随干扰小幅下降 | 随干扰显著下降 (语法乱) |

## 通用价值 (别处也能用上)

1. **探测内部表示**: 不依赖可解释性工具, 通过行为干预显影表示结构。
2. **验证"直觉=编译结构"**: 若直觉均匀分布而结构集中, 佐证直觉是
   结构的编译 (无 canonical 偏置), 结构是语法的确定执行。
3. **跨任务可迁移**: 任何"双路径 (快/慢)"系统都可用此方法探测
   两路径的表示差异 (蒸馏模型, 推理加速器, MoE 等)。
4. **干扰强度扫描**: 拆 N 个 token 的梯度实验, 测系统对语法歧义的鲁棒性。

## 与 EXP-61g 的关系

EXP-61g 测 prefix vs infix 的收敛差异 (判定 0.927 vs 0.931, 差异小 —
用户观察正确, 单独语法格式差异不显)。EXP-61h 用干扰 token 放大
直觉/结构差异, 是 EXP-61g 的深入 — 语法格式本身差异小,
但**语法歧义 (同 token 多义) 会放大两路径分化**。
