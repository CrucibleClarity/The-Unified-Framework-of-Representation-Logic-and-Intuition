## 观测 C: 临界带内分层扫描

σ = 0.25 / 0.50 / 0.75 三层的 |ζ(σ+it)| vs t: 零点在同一 t 处每层同时
收缩 — 临界带内零点是"整层穿透"结构 (零点不是单层的, 是 (σ,t) 平面
上穿透所有 σ 层的点)。

## 观测 D: 伪范数 (分裂复数度量, 欧拉圆正交)

z = ζ(σ+it) 的伪范数 x²-y² 在类时/类空间振荡, 反复穿越两个欧拉圆
(x²-y² = +1 与 -1)。零点附近 ζ 的像回到原点 (穿过两圆)。

## 观测 E: 后继迭代翻译级数 (先前记录)

假实轴刻度 n ↦ (i^i)^n = e^{-nπ/2} 翻译 1/n^s → e^{nπs/2}:
- 几何级数, 公比 |e^{πs/2}| = e^{πσ/2}, 收敛 ⟺ Re(s) < 0
- 极点 s = 4ik (k∈ℤ, 纯虚轴, 周期 4i), 无零点
- 翻译后不再是 ζ (调和级数 → 几何级数); 收敛域从 Re>1 翻转到 Re<0
- "因为 i 而收敛"的精确含义 = 公比由 i^i = e^{-π/2} < 1 决定

## 结论

1. 临界带内零点数值上都在 σ=1/2 (前 6 个, 敏感度 10⁸) — 数值证据
2. 观测不构成证明: 零点位置控制需要分析学 (显式公式/零点计数)
3. 翻译级数的极点族 (4ik) 与素数因子零点 (2πik/ln p) 同在 Re=0 —
   假实轴的 i 结构家族, 但不是 1/2

### F2: 谐波素数圆 (半径 2πk/ln p, 即素数因子零点公式的量)

### F5: 对偶轴设计 (用户方向: 新增欧拉圆轴使素数-零点合一)

- 素数: pₙ ~ n ln n (素数定理, 第 n 个素数)
- 零点: γₙ ~ 2πn/ln n (零点计数粗糙反函数; 精确: Gram 点近似
  γₙ ≈ 2π(n-11/8)/W((n-11/8)/e))
- **编号对偶**: pₙ 与 γₙ 共享"第 n 个"编号 — 在序号轴上天然重合 (平凡)
- **尺度对偶**: ln 互换 + 2π 因子 (素数定理 ↔ 零点计数定理) — 经典对偶,
  连接 = 显式公式 ψ(x) = x - Σ x^ρ/ρ (零点 γ 决定素数振荡频率 2π/γ)
- 待设计: 对偶轴坐标 u, 使 u(pₙ) ≈ u(γₙ) 有自然几何意义

## 观测 G: 对偶轴设计 — 计数函数作为正交欧拉圆系数 (用户方向 2026-08-21)

### G1: 朴素 n/ln n 刻度 (数值否决)

欧拉圆 i 刻度单位 n/ln n, 零点系数 γₙ·ln n/n:
n=8..30 稳定在 ~11.5, 不是 2π=6.28 (差 1.83 倍)。
朴素 γₙ ~ 2πn/ln n 忽略 ln ln n 修正, 不收敛。

### G2: 计数函数轴 (精确设计)

| 欧拉圆 | 系数轴刻度 | 第 n 个对象 | 系数 |
|---|---|---|---|
| 欧拉圆 1 (发散轴) | π(x) ~ x/ln x | 素数 pₙ | π(pₙ) = n 精确 |
| 欧拉圆 i (周期轴) | N(y) ~ y·ln y/(2π) | 零点 γₙ | N(γₙ) = n 精确 |

- n/ln n 直觉 = 素数定理 π(x) ~ x/ln x 的近似
- 零点侧对应物 = 零点计数 N(y) ~ (y/2π)·ln(y/2πe) (含 ln ln 修正)
- 第 n 个素数 ↔ 第 n 个零点在 (π, N) 系数轴上精确共享系数 n — 重合

### G3: 数学本质 (诚实)

1. 定义层精确: pₙ = π⁻¹(n), γₙ = N⁻¹(n) — 序号共享平凡成立
2. 非平凡对应: π ~ x/ln x 与 N ~ y ln y/(2π) 的互反结构 (ln 互换 + 2π),
   连接 = 显式公式 ψ(x) = x - Σ x^ρ/ρ — 零点-素数对偶的经典内容
3. 不证明 RH: 序号轴不区分实部, 零点位置信息未进入坐标系
4. 0pat: 素数定理与零点计数均为经典 (引用); 计数轴 = 观测框架, 非新定理

## 观测 H: 1/e/i/π 半径搭配穷举 (用户方向 2026-08-21)

### H1: 固定半径圆不可能同时承载

素数圆半径 √pₙ ∈ [1.4, 10.6], 零点圆半径 γₙ ∈ [14.1, 101.3] — 尺度差 ~10 倍,
任何固定 (r, ir) 正交圆对不能同时承载素数圆和零点圆 (平凡尺度事实)。

### H2: γₙ/√pₙ (素数圆↔零点圆半径比) 穷举

均值 9.667 (n=1..30), 变异 7.6%。最近自然常数:
- π² = 9.870 (Δ=2.1%) 最近
- 3π = 9.425 (Δ=2.5%)
- eπ = 8.540 (Δ=11.7%)

趋势 9.99 → 9.93 → 9.24 → 9.50 → 9.16 → 9.02 → 9.53 (非单调)。

### H3: 渐近判定 (非 π² 结构)

γₙ/√pₙ 渐近主项 ~ 2π√n/(ln n)^{3/2} — 随 n 增长 (n=30: ~9.5, n=10⁶: ~120)。
n≤30 的稳定 = √n 增长与 ln^{3/2} 增长恰好抵消的偶然平稳, 非常数结构。

### H4: 三圆搭配 (e, ie), (π, iπ), (eπ, eiπ)

落圆系数变异 65-67%, 无结构。最优折中半径 10.74 与 eπ/π² 均不精确吻合。
其他函数形式 (γ²/p, γ/ln p, γ·ln p/p) 变异 12-61%, 均不如 γ/√p。

### 结论

1/e/i/π 全部搭配穷举完毕: 无素数-零点重合结构。
γₙ/√pₙ ≈ π² 是 n≤30 的巧合平稳, 渐近漂移, 非数学结构。

### J3: 投影丢失结构
