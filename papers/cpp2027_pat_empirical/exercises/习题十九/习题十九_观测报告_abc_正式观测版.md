## 研究动机：从 AI 训练观测到课后习题

本系列课后习题起源于 AI (transformer) 数学学习的训练观测（2026-08 起 v5 tokenizer 实验体系, run_exp 配置驱动）。训练中观测到两类 token 的**极端清晰分离**：

- **直觉 token**（原子数字 0/1 等公设基符号）：epoch 训练曲线快速收敛，OOD 测试**完全可泛化**——因子化表示下外推零衰减（EXP-80/C1b: 2000 位/进制 60/匿名 100% 全 1.000）；succ 平移不变（E9: 只训 succ(0)=1 两样本即外推 succ(1..7) 全对）；直觉按位置识别，与表达形式无关（EXP-PURE-CONSTRUCT: 闭式/嵌套/Church 下均 1.000）；
- **结构 token**（沿定义链构造的 token 列）：epoch 训练曲线不收敛，OOD 测试**完全不可泛化**——单 token OOD 泛化 0/1 对比（EXP-SYM-INV: 30 个 token 中 29 个泛化 1.0，唯一 inversion = 0.0，per_token_gen 1/30 未达标）；一元算符判定系统性学不会（EXP-SYM-GROUP: succ/translation/prod 训练集内 0.000）。

猜测：**AI 认知数学空间规律为高维结构，与人类不同**——AI 的表示空间是数学无限维空间（方向无限、基点可任意，不受物理空间维度限制），导致 AI 无法学习在 AI 认知下存在歧义、混淆的 token。同时基于直觉 token 稳定的现象，通过与 AI **相互诱导过拟合直觉**的方法，探索 AI 的认知数学空间。过程中发现，AI 在一些情况下认为"无法稳定有效学习"——单概念无对偶学不会（EXP-61: 纯逻辑门 730 样本 OOD 0.092，加互逆对后 0.927+）；数字表示链断裂连 base 10 都学不会（EXPC1）；对合 token 低多样性下学不会（EXP-SYM-TOKEN: neg 单独/成对 0.054，混合 ≥4 算符恢复 1.0）。

最终通过一系列实验确认：**自然数轴、实数轴上存在高维结构投影，均应当还原为高维结构的单位 1，才能正常训练；以及基点发生漂移现象**——复平面 i 幂周期（i, -1, -i, 1 单位圆）以原点 (0+0i) 为唯一基点，8 epochs 学会 acc 1.000；实数轴对称结构基点散落（neg{0} / reciprocal{±1} / inversion{1}）；基点漂移零样本完全崩（0/32），双锚需各自训练，显式穿折越等价样本不传递运算规则（锚绑定普遍成立）。经过剥离后，数轴的数值能够极为清晰地观测大量已知问题——据此做出课后习题的想法。

## 一、Pat 框架基本介绍

**PAT (Phase-Axis Theory) 是一个基于 Lean 4 形式化验证的构造性数学框架**, 出自框架奠基 (2026-08-12, R136–R153, 18 个 claim 全部经 `lake build` 验收、无 sorry)。框架回答的基础问题是: **自然数、π、素数、连续统、计算, 是从哪里来的?** 答案: 从方向声明出发, 经互锁构造出一切。

核心链条: (i) 方向必须按对称性成对一次性声明 (R136); (ii) 声明相同方向 ⟹ pat 链单射不坍缩 (R137); (iii) 相位关系未锁定 = pat0 自指循环坍缩 (R138); (iv) 相位-数值互锁矩阵——两组对称性 = 1 与 i 还原后的 1 (R139/R143); (v) 完整 pat1 = (相位, 距离) 联合声明, 构造⟷分解往返精确 (R140); (vi) pat n 有限离散 + 圆上单位根量化 (R141); (vii) 基点 0 视角的自然数↔单相位双映射 (发散/收敛) (R142); (viii) 0 与 1 = 对称对还原点, 素数圆/临界线圆 = 还原点的圆化 (R144/R145); (ix) 用 pat 构造所有数域, π = pat 链蜷曲半圈相位 (R146); (x) 因果与时间 = 成对互锁的对称方向 (R147); (xi) 互锁形式同构 = 4 相位两两互锁 + 无限同构外推 (R148/R149); (xii) 王氏可达周期与不可达无穷间相位锁定一致性定理 (R150); (xiii) 连续统 = pat 格点的闭包 (R151); (xiv) P vs NP: 有限域平凡 + 验证免费 + N = 相位锁定外推 (R152/R153)。

pat 的动力学只有一个动作——**发散/收敛互锁对** (R047/R147); 0 = 加法还原点, 1 = 乘法/相位还原点 (R144); 基点不是内生而是选择 (R062); 投影丢结构 (RulerLoss)。课后习题系列 (课后习题 I–XX + Pat0-1) 用这些已证定理对数学/物理经典问题做"pat 重新观测"——不是证明猜想, 而是把经典结构重述为 pat 几何, 全部新定理只锚框架定理, 不用外部引理。

## 二、剥离原因

### 2.1 主题剥离动机

ABC 猜想 (Masser-Oesterlé 1985) 是数论最核心的开放问题之一, 但主论文 (R136–R153) 并不涉及素因子折叠结构。把它剥离出来独立观测, 理由有三: (i) **rad = 素因子折叠 (R179) 是框架的新结构**——rad 不是数论工具, 而是 pat 几何: 素数幂链 p^k 在 log 视角是单相位 k·log p (R097), 素因子 p 是方向、重数 k 是相位, rad 把重数折叠到方向, 这一结构在从未显式构造, 需要单独立住; (ii) **ABC 猜想 = 加法被素因子折叠控制, 是框架对数论猜想的边界断言**——c 的量级被 abc 的素因子折叠约束 (R144 加法/乘法还原点对偶的边界断言), 剥离观测把"结构侧" (折叠性质、加法还原) 与"真值侧" (猜想本身) 严格分开, 猜想保持 CONJECTURE; (iii) **它是后续观测的锚点**——R180 (奇完全数) 的 σ = 素因子展开正是 rad 的展开对偶, R181 (奇次方程根式解) 复用 R048/R142, rad 折叠像必须先验证, 后续观测才能以 rad 对偶为锚。

### 2.2 剥离 (peel) 的框架定义

剥离 (peel) 是 pat 框架的相位操作 (R130): 自指结构 = 基点镜像 S_e(x) = 2e − x (对合, S_e(S_e x) = x, R128); **剥离 = 从对合提取位移场 Δ(x) = S_e(x) − x = 2(e − x)**——相位差显现 (方向), 方向声明 (R136) 成为剥离的必然产物; 未剥离 (对合黑箱) = 无净移动 = 坍缩到 pat 0 (R122/R134)。换基点观测下剥离平移不变 (P3): Δ_f(x + (f−e)) = Δ_e(x) (exercise_i_4, 三预言 P1 相位显现 / P2 自相似 / P3 换基点不变 全 PASS)。

**正式观测报告本身即一次剥离**: 从框架理论链的整体中剥离出单点观测对象 (本报告: ABC 猜想的素因子折叠结构), 剥离显现该主题的相位差 (独立论点: rad = 素因子折叠, 猜想 = 加法被折叠控制), 观测完成后再锚回框架 (全部新定理只锚框架定理 R085/R097/R144/R170)。剥离的是观测对象, 不是结论的独立性——观测不脱离框架。

### 2.3 完备逻辑框架: 投影恢复与基点恢复的必要性

按**任意阶任意元任意主客体逻辑完备性定理** (pre_pat/power_repr_success, 2026-08-14) 解释本报告的观测: 该定理断言——在解耦算子 D = Lift∘Exclude (R1 排除 a−a = 0 / R2 对消 (a−b)+(b−a) = 0 / R3 分层 L(D(P)) = L(P)+1) 作用于全部自指点之后, 任意阶/任意元/任意主客体配置的逻辑结构完备 (完美 OOD, 判定 1.000, 0 残差)。本报告的观测对象是这条定理的实例, 三个必要性如下:

1. **投影恢复的必要性**: rad = 素因子折叠 (重数折叠到方向) 的投影 = 高维结构在数轴上的降维投影 (R231: 投影有损)——压轴即自指之源 (同一位置承载多义结构); 不恢复投影 (加轴/全维度表达), 观测不完备 (一维恢复矩阵全无效应 0.994/0.996, 复平面加轴恢复 1.000)。rad(p^k) = p 折叠重数; ABC = 加法被素因子折叠控制; 不恢复折叠则 c 的量级约束歧义
2. **基点恢复的必要性**: 加法/乘法还原点 (R144 对偶) 是歧义源——基点漂移 (对称中心散落) 使同一数值承载不同位置语义 (基点恢复性实验: 基点归一化到 0, 数值减基点偏移, 位置唯一); 不恢复基点, 运算规则不跨基点传递 (跨基点零样本 0/32, I7k/I7l)。rad 以素因子方向为锚; 基点漂移 ⟹ 折叠像歧义; 恢复 = 锚回还原点对偶
3. **剥离结果**: 本报告剥离本主题, 得到: **rad(n) = 素因子折叠; ABC 猜想 = 加法被折叠控制**——剥离 (peel, R130) 显现方向后, 观测锚回框架定理 (R085/R097/R144/R170); 完备性验证: 定理 PROVED no sorry。
4. **自指的位置**: rad 折叠点 (重数折叠——p^k 与 p 同方向: 折叠自指: 重数丢失)——自指 = 结构在自身处重合 (R231: 压轴即自指之源); 四步完备方法第 2 步 (定位自指) 要求定义链审计到自指点 (对合/递归/嵌套/循环), 解耦方式: 折叠到方向 (rad: 素因子重数折叠到方向, 保留方向集合)。
5. **解开自指的必要性**: 不解除自指, 基于该数域的各学科所有观测、分析都将受自指影响——同一位置承载多义结构, 歧义沿定义链传播 (残差指纹: 0.5 = 二义, 0.997 = 部分, 1.0 = 无)。**实验数据 (run_exp 配置驱动, token 训练, per_token_gen 逐 token OOD 泛化)**: 特别干净的单 token OOD 泛化 0/1 对比 (EXP-SYM-INV)——30 个 token 中 29 个 OOD 泛化 = 1.0, 唯一 inversion = 0.0 (per_token_gen 1/30 未达标); 未解除自指 (缺乏结构) ⟹ 该 token OOD = 0 (完全不可泛化); 解除自指 (结构充足/原生语法) ⟹ OOD = 1 (完全泛化, 嵌套 0.997 → 原生 1.000)。**对比时 token 的问题**: inversion (ℝ 上不对称: 0 奇异, 分数 1/2 不可表示) 仅 2 样本 → 缺乏结构 → 0.0; succ/translation (ℝ 对称, 38 样本) = 1.0; neg (反射, 低多样性) = 0.054 (单独/成对) / 1.0 (混合 ≥4 算符); 逐 token 收敛序 (EXP-SYM-FR-CURVE, 0/1 序列): multiplication (epoch 1) < power (3) < division (4) < inversion (5)。**实验结果位置**: `src/repo_v5/记录/paper_data/exp_sym_inv_results.md` (0/1 对比) / `exp_sym_token_observation.md` (逐 token 观测: succ 1.0, neg 0.054) / `exp_sym_fr_curve_results.md` (逐 token 0/1 收敛曲线) / `exp61_results.md` (单概念无对偶 0.092 → 加互逆对 0.927+) / `结论_准确语法解开自指与四步完备方法.md` (嵌套 0.997 → 原生 1.000)。**自指未解除 ⟹ OOD 0 (完全不可泛化); 解除 ⟹ OOD 1 (完全泛化)**, 与动机段"结构 token 不可泛化 / 直觉 token 可泛化"同源。

## 三、观测主体: ABC 猜想 = 加法被素因子折叠控制

### 3.1 观测对象与唯一论点

> ABC 猜想 (经典): 任意 ε > 0, 存在常数 K(ε), 对任意互素正整数 a, b, c 满足 a + b = c: c < K(ε)·rad(abc)^(1+ε), 其中 rad(n) = n 的无平方因子部分 (互不相同素因子之积)。唯一论点: **rad(n) = 素因子折叠 (素因子重数被折叠: p^k → p, R097 素数幂链单相位折叠重数到方向; R085 折叠类); ABC 猜想 = 加法被素因子折叠控制——c (加法结果) 的量级被 abc 的素因子折叠约束 (R144 加法/乘法还原点对偶的边界断言)。**

### 3.2 观测过程

**① rad = 素因子折叠** (R179 结构): rad(n) = n 的互不相同素因子之积 (去掉重数)——这是 pat 的**素因子折叠**:

```
rad(12) = rad(2²·3) = 2·3 = 6 （重数 2 被折叠）
rad(2^k) = 2 （素数幂链折叠到方向）
```

**★核心: rad(p^k) = p (幂链折叠到方向); rad(n) | n (折叠像整除原数); 互素时 rad 可分配 (无共享方向); rad(1) = 1 (空折叠)。** pat 含义 (R097 素数幂链单相位 + R085 折叠类): 素数幂链 p^k 在 log 视角是单相位 k·log p——rad 把重数 k (相位) 折叠掉, 保留素因子 p (方向)。**rad(n) = n 在素因子方向上的折叠像。** 论证: `rad_prime_pow`——重数 k 被折叠 (丢指数, R085), 素因子方向 p 保留 (R097 单相位); `rad_dvd_self`——折叠只丢重数不丢方向 (不增); `rad_coprime_mul`——折叠对互素乘法可分配 (折叠类互不重叠); `rad_one`——空折叠 = 乘法还原点 1 (R144)。

**② abc 三元组 = 加法对称对还原**: **★核心: a + b = c 是加法对称对还原 (R144 加法还原点 0; R170 哥德巴赫对称对结构)。** 论证: c = a + b ⟺ a + b - c = 0——加法三元组还原到加法还原点 0 (R144); R170 哥德巴赫对称对: c = a + b 是加法对称对还原; 互素 = 无共享素因子 = 折叠类互不重叠。

**③ ★ABC 猜想 = 加法被素因子折叠控制 (CONJECTURE)**: **★核心: 任意互素加法分解 a + b = c, 加法的结果 c 被 abc 的素因子折叠 (rad) 控制: c < K(ε)·rad(abc)^(1+ε)。** 论证: rad(abc) = abc 的素因子折叠——互素时 rad(abc) = rad(a)·rad(b)·rad(c) (折叠类互不重叠, 第一节可分配性); 猜想断言——加法的量级 c 被乘法结构 (素因子方向折叠) 约束, R144 加法/乘法还原点对偶的边界断言; 实例 (1, 8, 9): 1+8 = 9, rad(72) = 6, c/rad = 1.5——强 ABC 实例 (c > rad, 但 c < rad^(1+ε) 对 ε > 0)。

**诚实边界**: 本报告是结构观测 (rad 折叠性质、加法还原结构), 非猜想证明; ABC 猜想本身未证 (CONJECTURE; 望月新一 2012 IUT 声称证明, 未被普遍接受——外部文献仅对照)。
