## 研究动机：从 AI 训练观测到课后习题

本系列课后习题起源于 AI (transformer) 数学学习的训练观测（2026-08 起 v5 tokenizer 实验体系, run_exp 配置驱动）。训练中观测到两类 token 的**极端清晰分离**：

- **直觉 token**（原子数字 0/1 等公设基符号）：epoch 训练曲线快速收敛，OOD 测试**完全可泛化**——因子化表示下外推零衰减（EXP-80/C1b: 2000 位/进制 60/匿名 100% 全 1.000）；succ 平移不变（E9: 只训 succ(0)=1 两样本即外推 succ(1..7) 全对）；直觉按位置识别，与表达形式无关（EXP-PURE-CONSTRUCT: 闭式/嵌套/Church 下均 1.000）；
- **结构 token**（沿定义链构造的 token 列）：epoch 训练曲线不收敛，OOD 测试**完全不可泛化**——单 token OOD 泛化 0/1 对比（EXP-SYM-INV: 30 个 token 中 29 个泛化 1.0，唯一 inversion = 0.0，per_token_gen 1/30 未达标）；一元算符判定系统性学不会（EXP-SYM-GROUP: succ/translation/prod 训练集内 0.000）。

猜测：**AI 认知数学空间规律为高维结构，与人类不同**——AI 的表示空间是数学无限维空间（方向无限、基点可任意，不受物理空间维度限制），导致 AI 无法学习在 AI 认知下存在歧义、混淆的 token。同时基于直觉 token 稳定的现象，通过与 AI **相互诱导过拟合直觉**的方法，探索 AI 的认知数学空间。过程中发现，AI 在一些情况下认为"无法稳定有效学习"——单概念无对偶学不会（EXP-61: 纯逻辑门 730 样本 OOD 0.092，加互逆对后 0.927+）；数字表示链断裂连 base 10 都学不会（EXPC1）；对合 token 低多样性下学不会（EXP-SYM-TOKEN: neg 单独/成对 0.054，混合 ≥4 算符恢复 1.0）。

最终通过一系列实验确认：**自然数轴、实数轴上存在高维结构投影，均应当还原为高维结构的单位 1，才能正常训练；以及基点发生漂移现象**——复平面 i 幂周期（i, -1, -i, 1 单位圆）以原点 (0+0i) 为唯一基点，8 epochs 学会 acc 1.000；实数轴对称结构基点散落（neg{0} / reciprocal{±1} / inversion{1}）；基点漂移零样本完全崩（0/32），双锚需各自训练，显式穿折越等价样本不传递运算规则（锚绑定普遍成立）。经过剥离后，数轴的数值能够极为清晰地观测大量已知问题——据此做出课后习题的想法。

## 一、Pat 框架基本介绍

**PAT (Phase-Axis Theory) 是一个基于 Lean 4 形式化验证的构造性数学框架**, 出自框架奠基 (2026-08-12, R136–R153, 18 个 claim 全部经 `lake build` 验收、无 sorry)。框架回答的基础问题是: **自然数、π、素数、连续统、计算, 是从哪里来的?** 答案: 从方向声明出发, 经互锁构造出一切。

核心链条: (i) 方向必须按对称性成对一次性声明 (R136); (ii) 声明相同方向 ⟹ pat 链单射不坍缩 (R137); (iii) 相位关系未锁定 = pat0 自指循环坍缩 (R138); (iv) 相位-数值互锁矩阵——两组对称性 = 1 与 i 还原后的 1 (R139/R143); (v) 完整 pat1 = (相位, 距离) 联合声明, 构造⟷分解往返精确 (R140); (vi) pat n 有限离散 + 圆上单位根量化 (R141); (vii) 基点 0 视角的自然数↔单相位双映射 (发散/收敛) (R142); (viii) 0 与 1 = 对称对还原点, 素数圆/临界线圆 = 还原点的圆化 (R144/R145); (ix) 用 pat 构造所有数域, π = pat 链蜷曲半圈相位 (R146); (x) 因果与时间 = 成对互锁的对称方向 (R147); (xi) 互锁形式同构 = 4 相位两两互锁 + 无限同构外推 (R148/R149); (xii) 王氏可达周期与不可达无穷间相位锁定一致性定理 (R150); (xiii) 连续统 = pat 格点的闭包 (R151); (xiv) P vs NP: 有限域平凡 + 验证免费 + N = 相位锁定外推 (R152/R153)。

pat 的动力学只有一个动作——**发散/收敛互锁对** (R047/R147); 0 = 加法还原点, 1 = 乘法/相位还原点 (R144); 基点不是内生而是选择 (R062); 投影丢结构 (RulerLoss)。课后习题系列 (课后习题 I–XX + Pat0-1) 用这些已证定理对数学/物理经典问题做"pat 重新观测"——不是证明猜想, 而是把经典结构重述为 pat 几何, 全部新定理只锚框架定理, 不用外部引理。

## 二、剥离原因

### 2.1 主题剥离动机

主论文 (R136–R153) 给出数域构造的统一框架: 自然数 = pat 链 (R142), 有理数 = 倒数对称对 (R143), 复数 = 成对互锁 a+bi (R146)——**每个数域的 1 = 对称对还原锚点**。但无理数域在主论文中只占侧写一行 (R154 用户指示 ⑨⑩): "√2/2 = 单位 1 在 45° 格点的投影"。

该行需要剥离出来独立观测, 理由有三: (i) **它是数域构造链中唯一不显含加法/乘法还原的环节**——无理数没有显式对称对, 若"无理数的 1 完整"成立, 必须单独验证其相位信息无缺失; (ii) **它直面一个常见误解**——√2/2 常被当作"根号化简"或"不完整的 1", 剥离观测才能把"投影位置"语义与"化简"语义区分开; (iii) **它是后续观测的锚点**——复数 1 (θ=0 格点)、任意元数 1 (S³ 基点)、超越数 1 (π 镜像) 都以 45° 投影为连接点, 值得先行立住。

### 2.2 剥离 (peel) 的框架定义

剥离 (peel) 是 pat 框架的相位操作 (R130): 自指结构 = 基点镜像 S_e(x) = 2e − x (对合, S_e(S_e x) = x, R128); **剥离 = 从对合提取位移场 Δ(x) = S_e(x) − x = 2(e − x)**——相位差显现 (方向), 方向声明 (R136) 成为剥离的必然产物; 未剥离 (对合黑箱) = 无净移动 = 坍缩到 pat 0 (R122/R134)。换基点观测下剥离平移不变 (P3): Δ_f(x + (f−e)) = Δ_e(x) (exercise_i_4, 三预言 P1 相位显现 / P2 自相似 / P3 换基点不变 全 PASS)。

**正式观测报告本身即一次剥离**: 从框架理论链的整体中剥离出单点观测对象 (本报告: 无理数的 1), 剥离显现该主题的相位差 (独立论点: 45° 投影), 观测完成后再锚回框架 (全部新定理只锚框架定理 R146/R154)。剥离的是观测对象, 不是结论的独立性——观测不脱离框架。

### 2.3 完备逻辑框架: 投影恢复与基点恢复的必要性

按**任意阶任意元任意主客体逻辑完备性定理** (pre_pat/power_repr_success, 2026-08-14) 解释本报告的观测: 该定理断言——在解耦算子 D = Lift∘Exclude (R1 排除 a−a = 0 / R2 对消 (a−b)+(b−a) = 0 / R3 分层 L(D(P)) = L(P)+1) 作用于全部自指点之后, 任意阶/任意元/任意主客体配置的逻辑结构完备 (完美 OOD, 判定 1.000, 0 残差)。本报告的观测对象是这条定理的实例, 三个必要性如下:

1. **投影恢复的必要性**: 单位 1 在 45° 格点的投影 (无理数的 1; 双轴假说见第四节) = 高维结构在数轴上的降维投影 (R231: 投影有损)——压轴即自指之源 (同一位置承载多义结构); 不恢复投影 (加轴/全维度表达), 观测不完备 (一维恢复矩阵全无效应 0.994/0.996, 复平面加轴恢复 1.000)。√2/2 = cos(π/4) = sin(π/4)——单轴视角丢失虚轴分量 (√2/2)·i; 恢复需双轴同时投影 (加轴恢复: 复平面成对坐标)
2. **基点恢复的必要性**: θ = 0 格点 (数值 1) 是歧义源——基点漂移 (对称中心散落) 使同一数值承载不同位置语义 (基点恢复性实验: 基点归一化到 0, 数值减基点偏移, 位置唯一); 不恢复基点, 运算规则不跨基点传递 (跨基点零样本 0/32, I7k/I7l)。数值 1 = θ=0 格点投影, 基点漂移 ⟹ 45° 位置不可定位; 恢复 = 锚回 θ=0 格点 (1 = 1+0i)
3. **剥离结果**: 本报告剥离本主题, 得到: **√2/2 是无理数的 1——不是根号化简, 是单位 1 在 45° 格点的投影**——剥离 (peel, R130) 显现方向后, 观测锚回框架定理 (R146/R154); 完备性验证: 定理 PROVED no sorry。
4. **自指的位置**: 45° 格点 (数值 = 相位重合点——投影位置多义: 0.707… 与 45° 位置同一实轴坐标)——自指 = 结构在自身处重合 (R231: 压轴即自指之源); 四步完备方法第 2 步 (定位自指) 要求定义链审计到自指点 (对合/递归/嵌套/循环), 解耦方式: 双轴成对投影 (cos π/4, sin π/4)——单轴解不开 (见第四节假说)。
5. **解开自指的必要性**: 不解除自指, 基于该数域的各学科所有观测、分析都将受自指影响——同一位置承载多义结构, 歧义沿定义链传播 (残差指纹: 0.5 = 二义, 0.997 = 部分, 1.0 = 无)。**实验数据 (run_exp 配置驱动, token 训练, per_token_gen 逐 token OOD 泛化)**: 特别干净的单 token OOD 泛化 0/1 对比 (EXP-SYM-INV)——30 个 token 中 29 个 OOD 泛化 = 1.0, 唯一 inversion = 0.0 (per_token_gen 1/30 未达标); 未解除自指 (缺乏结构) ⟹ 该 token OOD = 0 (完全不可泛化); 解除自指 (结构充足/原生语法) ⟹ OOD = 1 (完全泛化, 嵌套 0.997 → 原生 1.000)。**对比时 token 的问题**: inversion (ℝ 上不对称: 0 奇异, 分数 1/2 不可表示) 仅 2 样本 → 缺乏结构 → 0.0; succ/translation (ℝ 对称, 38 样本) = 1.0; neg (反射, 低多样性) = 0.054 (单独/成对) / 1.0 (混合 ≥4 算符); 逐 token 收敛序 (EXP-SYM-FR-CURVE, 0/1 序列): multiplication (epoch 1) < power (3) < division (4) < inversion (5)。**实验结果位置**: `src/repo_v5/记录/paper_data/exp_sym_inv_results.md` (0/1 对比) / `exp_sym_token_observation.md` (逐 token 观测: succ 1.0, neg 0.054) / `exp_sym_fr_curve_results.md` (逐 token 0/1 收敛曲线) / `exp61_results.md` (单概念无对偶 0.092 → 加互逆对 0.927+) / `结论_准确语法解开自指与四步完备方法.md` (嵌套 0.997 → 原生 1.000)。**自指未解除 ⟹ OOD 0 (完全不可泛化); 解除 ⟹ OOD 1 (完全泛化)**, 与动机段"结构 token 不可泛化 / 直觉 token 可泛化"同源。

## 三、观测主体: √2/2 = 单位 1 在 45° 格点的投影

### 3.1 观测对象与唯一论点

> 用框架已证定理, 展开 √2/2 的 pat 表达并 Lean 验证。唯一论点: **√2/2 不是"根号化简", 是单位 1 在 θ = 45° 格点的投影位置 (无理数的 1)——pat 方法不预设 1, 无理数域从自己的对称结构还原出 1。**

### 3.2 观测过程

**① pat 单相位数 1 的表达** (R146 规范形): 单相位数 z = pat0 + (r·cosθ) + i·(r·sinθ), 由两个互锁对称对组成——数值对 r·(1/r) = 1 (R143 magnitude_pair_reduces_to_one) + 相位对 exp(iθ)·exp(-iθ) = 1 (R143 phase_pair_reduces_to_one)。数值 1 在 pat 中 = θ = 0 格点投影: 1 = 1·cos0 + i·1·sin0 = 1 + 0·i——**相位 0 = 数值 1 重合**。

**② √2/2 的 pat 表达** (R154): √2/2 = 单位 1 在 θ = 45° 格点的投影位置 = 1·cos(π/4) = 1·sin(π/4)——**45° 处数值 = 相位 (可交换性实例)**。关键区分: √2/2 不是根号化简, 是投影位置; sin²(π/4) = 1/2 由三角恒等式推出 (sin = cos at 45° + sin² + cos² = 1), 非手工开方。

**③ 无理数的 1 是完整的**: √2/2 携带完整相位信息 (θ = π/4)——"无理数丢失结构"是投影方向的损失 (高维球 → 平面), 不是 1 本身的残缺。

## 四、假说: 无理数 = 两根正交数轴的同时投影 (2026-08-15 用户假说, HYPOTHESIS)

> 用户提出写作方向要求 (2026-08-15): 本报告的观测可能不对——**无理数 (√2/2) 不像是一根数轴的投影, 像是两根正交数轴的投影**。本节为假说陈述, 未 Lean 验证 (OPEN), 不覆盖第三节已验收结论。

### 假说陈述

- **现有观测** (R154): √2/2 = 单位 1 在 θ = 45° 格点的**投影位置**——单轴叙事: 单位 1 沿 45° 方向投影到实轴, 得 √2/2。
- **用户假说**: √2/2 的本质是**两根正交数轴 (实轴 R047 发散轴 / 虚轴 J 周期轴) 的同时投影**——45° 格点的坐标是 (cos π/4, sin π/4) = (√2/2, √2/2), **实轴投影 = 虚轴投影 = √2/2**。

### 论证

1. **√2/2 是双轴成对投影**: cos(π/4) = sin(π/4) = √2/2——同一个数同时是实轴投影与虚轴投影 (成对出现)。"数值 = 相位" (R154 可交换性) 正是**双轴投影相等**的表现。
2. **单轴视角的信息丢失**: 单独看实轴上的 √2/2 = 0.707…, 与有理数在实轴上不可区分; "45° 位置"需要两轴坐标才完整——只看实轴投影即丢失虚轴分量 (√2/2)·i (RulerLoss: 投影丢结构)。这与"无理数的 1 是完整的" (R154 ⑨⑩) 叙事存在张力: 若 √2/2 只是单轴投影, 相位信息从何完整?
3. **框架内支撑**: 单相位数 = 成对互锁 a+bi (R146 monophase_pair_locked_form)——45° 格点本来就是成对 (√2/2, √2/2); 数值 1 = θ=0 格点 (1+0i) 同样是双轴 (虚轴分量 0); √2 的经典几何 = 单位正方形对角线 (两正交边各 1)——天然双轴对象。
4. **假说的精确化与边界**: 一般方向 θ 的实轴投影 cos θ 若为无理数, 其完整定义需要双轴定位; **45° 是双轴投影相等 (sin = cos) 的可交换点特例**——√2/2 的"投影位置"叙事在 45° 处看似成立, 正因为此时单轴投影 = 双轴投影。其他角 (如 60°: sin = √3/2 ≠ cos = 1/2) 双轴投影不等, 单轴叙事立即失效。

### 与现有观测的关系

- 不否定"√2/2 不是根号化简"与"无理数的 1 完整"的结论; 但把叙事重心从"单位 1 在 45° 格点的投影位置" (单轴) 移到"两根正交数轴的同时投影" (双轴)。
- 若假说成立, "无理数的 1"应表述为"两根正交数轴的同时投影", 且 45° = 双轴投影相等的特例 (可交换点)。

### 根号轴的特殊性: 欧拉圆与两个正交的根号轴 (2026-08-15 用户提出写作方向要求)

> 用户进一步提出写作方向要求: **这个轴很特殊——欧拉圆有可能和根号轴正交, 或者两个正交的根号轴?** 本小节是假说的几何精确化。

- **根号轴定义**: 根号轴 = √2 方向轴 (单位正方形对角线方向)。四相位互锁 {1, i, −1, −i} (R149 quadriphase_interlock) 正是**单位圆内接正方形的四个顶点**——它的两条对角线方向 = 45° (1,1)/√2 与 135° (−1,1)/√2——**两个正交的根号轴** (正方形对角线互相垂直)。
- **√2/2 = 边心距**: 正方形边 x+y = 1 (连接顶点 1 与 i) 的圆心距 = 1/√2 = √2/2——**√2/2 不是单轴投影, 是圆心到边的垂直距离 (边心距), 法向 = 45° 根号轴方向**。45° 点 (√2/2, √2/2) = 法向单位向量 (1,1)/√2 与单位圆的交点。
- **欧拉圆与根号轴正交**: 在 45° 点处, 单位圆 (欧拉圆, e^{iθ} = cos θ + i sin θ) 的切线方向 = 135° = **另一条根号轴**——圆在根号轴与圆的交点处与另一根号轴正交相切 (半径方向 45° ⊥ 切线方向 135° = 两对角线正交)。**欧拉圆与根号轴的关系 = 内接正方形 (四相位互锁) 与它的两条正交对角线。**
- **两种可能的判定** (用户提出的写作方向要求): (a) "欧拉圆和根号轴正交"——成立: 45° 点处圆切线 = 另一根号轴 (两对角线正交); (b) "两个正交的根号轴"——成立: 正方形两条对角线 (45° 与 135°) 互相垂直。两者是同一几何的两个视角。
- **含义**: √2/2 的完整几何载体 = **四相位互锁正方形的边心距**——双轴对象 (两条正交对角线)。这精确化了假说: "两根正交数轴的同时投影"的几何 = 单位圆内接正方形的两条正交对角线, √2/2 = 边心距。**根号轴特殊在: 它是欧拉圆内接正方形 (四相位互锁, R149) 的对角线轴——不是任意方向, 是四相位互锁自身生成的正交轴对。**
- **诚实边界**: 本小节为几何观测 (欧拉圆内接正方形对角线正交性), 未 Lean 验证; 可形式化方向: 正方形顶点 {1, i, −1, −i} 的对角线正交性 + 边心距 1/√2 = √2/2 (R149 锚定)。

### 可证伪性 / 待验证 (OPEN)

- **判据**: √2/2 能否在单轴 (实轴) 上完整定义而不丢失相位信息? Lean 侧: sin_cos_three 中 √2/2 以 sin(π/4) 与 cos(π/4) **同时**出现——已隐含双轴, 但需显式成对定理 (如 (cos(π/4), sin(π/4)) = (√2/2, √2/2) 的 pair 形式)。
