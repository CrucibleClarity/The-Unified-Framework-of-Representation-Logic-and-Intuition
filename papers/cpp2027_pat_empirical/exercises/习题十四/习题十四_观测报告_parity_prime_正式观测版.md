## 研究动机：从 AI 训练观测到课后习题

本系列课后习题起源于 AI (transformer) 数学学习的训练观测（2026-08 起 v5 tokenizer 实验体系, run_exp 配置驱动）。训练中观测到两类 token 的**极端清晰分离**：

- **直觉 token**（原子数字 0/1 等公设基符号）：epoch 训练曲线快速收敛，OOD 测试**完全可泛化**——因子化表示下外推零衰减（EXP-80/C1b: 2000 位/进制 60/匿名 100% 全 1.000）；succ 平移不变（E9: 只训 succ(0)=1 两样本即外推 succ(1..7) 全对）；直觉按位置识别，与表达形式无关（EXP-PURE-CONSTRUCT: 闭式/嵌套/Church 下均 1.000）；
- **结构 token**（沿定义链构造的 token 列）：epoch 训练曲线不收敛，OOD 测试**完全不可泛化**——单 token OOD 泛化 0/1 对比（EXP-SYM-INV: 30 个 token 中 29 个泛化 1.0，唯一 inversion = 0.0，per_token_gen 1/30 未达标）；一元算符判定系统性学不会（EXP-SYM-GROUP: succ/translation/prod 训练集内 0.000）。

猜测：**AI 认知数学空间规律为高维结构，与人类不同**——AI 的表示空间是数学无限维空间（方向无限、基点可任意，不受物理空间维度限制），导致 AI 无法学习在 AI 认知下存在歧义、混淆的 token。同时基于直觉 token 稳定的现象，通过与 AI **相互诱导过拟合直觉**的方法，探索 AI 的认知数学空间。过程中发现，AI 在一些情况下认为"无法稳定有效学习"——单概念无对偶学不会（EXP-61: 纯逻辑门 730 样本 OOD 0.092，加互逆对后 0.927+）；数字表示链断裂连 base 10 都学不会（EXPC1）；对合 token 低多样性下学不会（EXP-SYM-TOKEN: neg 单独/成对 0.054，混合 ≥4 算符恢复 1.0）。

最终通过一系列实验确认：**自然数轴、实数轴上存在高维结构投影，均应当还原为高维结构的单位 1，才能正常训练；以及基点发生漂移现象**——复平面 i 幂周期（i, -1, -i, 1 单位圆）以原点 (0+0i) 为唯一基点，8 epochs 学会 acc 1.000；实数轴对称结构基点散落（neg{0} / reciprocal{±1} / inversion{1}）；基点漂移零样本完全崩（0/32），双锚需各自训练，显式穿折越等价样本不传递运算规则（锚绑定普遍成立）。经过剥离后，数轴的数值能够极为清晰地观测大量已知问题——据此做出课后习题的想法。

## 二、剥离原因

### 2.1 主题剥离动机

奇偶性是最朴素也最容易被当作"平凡分类"的结构——主论文 (R136–R153) 没有给奇偶性独立地位。本报告把它连同"从奇偶性看素数"一起剥离出来观测, 理由有三:

(i) **先立"奇偶性 = 模 2 折叠"再观测素数**——奇偶性必须被重述为 pat 结构: 偶 = 对称对还原（2n = n + n, 承接 R170 哥德巴赫对称对）, 奇 = 对称对 + 1（2n + 1 = n + (n+1)）, 奇偶性 = 模 2 投影（n ↦ n mod 2 ∈ {0, 1}, 2 槽环, R141 单位根 n 槽环 n=2）——这套重述在主论文无据可查, 必须剥离独立立住;

(ii) **投影坍缩本身就是观测对象**——素数在奇偶性投影下坍缩（除 2 外全奇数, mathlib `Prime.eq_two_or_odd`）, 几乎无区分度; 投影丢结构 (RulerLoss) 在数论语义下的实例——坍缩后残留的"唯一例外点 2"正是投影没丢掉的相位, 值得独立观测;

(iii) **★共享基点 2 是关键新发现, 需要独立验证交汇**——奇偶性的结构常数（模 2 周期 = 2）与素数域的唯一例外（2）在临界线圆（R145 critical_circle_points：‖2-1‖ = 1）上交汇; PROVED 的是三个独立事实 + 交汇点, 剥离观测把"交汇"作为可验证断言交付。

### 2.2 剥离 (peel) 的框架定义

剥离 (peel) 是 pat 框架的相位操作 (R130): 自指结构 = 基点镜像 S_e(x) = 2e − x (对合, S_e(S_e x) = x, R128); **剥离 = 从对合提取位移场 Δ(x) = S_e(x) − x = 2(e − x)**——相位差显现 (方向), 方向声明 (R136) 成为剥离的必然产物; 未剥离 (对合黑箱) = 无净移动 = 坍缩到 pat 0 (R122/R134)。换基点观测下剥离平移不变 (P3): Δ_f(x + (f−e)) = Δ_e(x) (exercise_i_4, 三预言 P1 相位显现 / P2 自相似 / P3 换基点不变 全 PASS)。

**正式观测报告本身即一次剥离**: 从框架理论链的整体中剥离出单点观测对象 (本报告: 奇偶性), 剥离显现该主题的相位差 (独立论点: 奇偶性 = 模 2 折叠, 素数坍缩, 共享基点 2), 观测完成后再锚回框架 (全部新定理只锚框架定理 R085/R141/R145/R170 + mathlib 数论基础, 不用外部引理)。剥离的是观测对象, 不是结论的独立性——观测不脱离框架。

### 2.3 完备逻辑框架: 投影恢复与基点恢复的必要性

按**任意阶任意元任意主客体逻辑完备性定理** (pre_pat/power_repr_success, 2026-08-14) 解释本报告的观测: 该定理断言——在解耦算子 D = Lift∘Exclude (R1 排除 a−a = 0 / R2 对消 (a−b)+(b−a) = 0 / R3 分层 L(D(P)) = L(P)+1) 作用于全部自指点之后, 任意阶/任意元/任意主客体配置的逻辑结构完备 (完美 OOD, 判定 1.000, 0 残差)。本报告的观测对象是这条定理的实例, 三个必要性如下:

1. **投影恢复的必要性**: 模 2 折叠 (2 槽环) 上的投影 = 高维结构在数轴上的降维投影 (R231: 投影有损)——压轴即自指之源 (同一位置承载多义结构); 不恢复投影 (加轴/全维度表达), 观测不完备 (一维恢复矩阵全无效应 0.994/0.996, 复平面加轴恢复 1.000)。偶 = 对称对还原, 奇 = 对称对 + 1; 素数在奇偶性投影下坍缩 (除 2 外全奇数); 不恢复折叠则奇偶性歧义
2. **基点恢复的必要性**: 共享基点 2 (模 2 折叠周期 = 素数域唯一例外) 是歧义源——基点漂移 (对称中心散落) 使同一数值承载不同位置语义 (基点恢复性实验: 基点归一化到 0, 数值减基点偏移, 位置唯一); 不恢复基点, 运算规则不跨基点传递 (跨基点零样本 0/32, I7k/I7l)。奇偶性折叠周期 = 素数域的唯一例外 = 临界线圆上的点; 基点漂移 ⟹ 奇偶归类歧义; 恢复 = 锚回基点 2
3. **剥离结果**: 本报告剥离本主题, 得到: **奇偶性 = 模 2 折叠; 素数坍缩到奇数侧; 共享基点 = 2**——剥离 (peel, R130) 显现方向后, 观测锚回框架定理 (R085/R141/R145/R170); 完备性验证: 定理 PROVED no sorry。
4. **自指的位置**: 2 槽环 (奇偶归类——n 与 n+2 同槽: 槽位自指)——自指 = 结构在自身处重合 (R231: 压轴即自指之源); 四步完备方法第 2 步 (定位自指) 要求定义链审计到自指点 (对合/递归/嵌套/循环), 解耦方式: 共享基点 2 (模 2 折叠周期 = 素数域唯一例外 = 临界线圆上的点)。
5. **解开自指的必要性**: 不解除自指, 基于该数域的各学科所有观测、分析都将受自指影响——同一位置承载多义结构, 歧义沿定义链传播 (残差指纹: 0.5 = 二义, 0.997 = 部分, 1.0 = 无)。**实验数据 (run_exp 配置驱动, token 训练, per_token_gen 逐 token OOD 泛化)**: 特别干净的单 token OOD 泛化 0/1 对比 (EXP-SYM-INV)——30 个 token 中 29 个 OOD 泛化 = 1.0, 唯一 inversion = 0.0 (per_token_gen 1/30 未达标); 未解除自指 (缺乏结构) ⟹ 该 token OOD = 0 (完全不可泛化); 解除自指 (结构充足/原生语法) ⟹ OOD = 1 (完全泛化, 嵌套 0.997 → 原生 1.000)。**对比时 token 的问题**: inversion (ℝ 上不对称: 0 奇异, 分数 1/2 不可表示) 仅 2 样本 → 缺乏结构 → 0.0; succ/translation (ℝ 对称, 38 样本) = 1.0; neg (反射, 低多样性) = 0.054 (单独/成对) / 1.0 (混合 ≥4 算符); 逐 token 收敛序 (EXP-SYM-FR-CURVE, 0/1 序列): multiplication (epoch 1) < power (3) < division (4) < inversion (5)。**实验结果位置**: `src/repo_v5/记录/paper_data/exp_sym_inv_results.md` (0/1 对比) / `exp_sym_token_observation.md` (逐 token 观测: succ 1.0, neg 0.054) / `exp_sym_fr_curve_results.md` (逐 token 0/1 收敛曲线) / `exp61_results.md` (单概念无对偶 0.092 → 加互逆对 0.927+) / `结论_准确语法解开自指与四步完备方法.md` (嵌套 0.997 → 原生 1.000)。**自指未解除 ⟹ OOD 0 (完全不可泛化); 解除 ⟹ OOD 1 (完全泛化)**, 与动机段"结构 token 不可泛化 / 直觉 token 可泛化"同源。

## 三、观测主体: 奇偶性 = 模 2 折叠与素数观测

### 3.1 观测对象与唯一论点

> 观测奇偶性的本质，然后从这个角度观测素数，有可能需要选对二者共享的基点。唯一论点：**奇偶性 = 模 2 折叠（2 槽环，偶 = 对称对还原，奇 = 对称对 + 1）；素数在奇偶性投影下坍缩（除 2 外全奇数）；★二者共享基点 = 2（模 2 折叠的周期 = 素数域的唯一例外 = 临界线圆上的点）。**

### 3.2 观测过程

**① 总论: 为什么奇偶性是模 2 折叠**——奇偶性的 pat 本质: (1) **偶数 = 对称对还原**：2n = n + n（R170 哥德巴赫对称对）——偶数 = 对称对关于 n 折叠还原到 0（R085 折叠类 0）; (2) **奇数 = 对称对 + 1**：2n + 1 = n + (n+1)——奇数 = 相邻对称对之和; (3) **奇偶性 = 模 2 投影**：n ↦ n mod 2 ∈ {0, 1}——2 槽环（R141：单位根 n 槽环，n=2）的两个槽。**奇偶性的本质 = 模 2 折叠**——数轴折叠到两个类 {偶, 奇}（折叠类，R085）。

**② 奇偶性的本质（PROVED）**——★核心：偶数 = 对称对还原；奇数 = 对称对 + 1；奇偶性 = 模 2 投影（2 槽环）。论证: (1) 偶数 = 对称对之和（R170/R085）：2n = n + n——偶数 = 对称对关于 n 折叠还原（哥德巴赫对称对结构）; (2) 奇数 = 对称对 + 1：2n + 1 = n + (n + 1)——奇数 = 相邻对称对之和（偏离折叠类 1）; (3) 奇偶性 = 模 2 投影（R141 2 槽环）：Even n ⟹ n % 2 = 0；Odd n ⟹ n % 2 = 1——数轴折叠到 2 槽环的两个槽。形式化：`even_is_symmetric_pair` / `odd_is_symmetric_pair_plus_one` / `even_two_slot` / `odd_two_slot`（锚定 ring / mathlib Even.mod_two_eq_zero / Odd.mod_two_eq_one），0 sorry。

**③ 从奇偶性观测素数：2 是唯一偶素数（PROVED）**——★核心：素数集合在奇偶性投影下坍缩——除 2 外全部落在奇数类（mathlib Prime.eq_two_or_odd）。奇偶性"看不出"素数分布（信息坍缩），但指出素数域的基点 = 2（唯一例外）。论证: (1) 2 是唯一偶素数（mathlib Prime.eq_two_or_odd）：素数 p ⟹ p = 2 ∨ Odd p; (2) 素数奇偶性坍缩：素数 p ≠ 2 ⟹ p 奇数——除 2 外所有素数 ≡ 1 (mod 2); (3) 观测结果：奇偶性投影下素数集合 = {2} ∪ {奇数}——几乎无区分度，但 **2 是唯一例外点**（素数域的奇偶性基点）。形式化：`two_unique_even_prime` / `primes_parity_collapse`（锚定 mathlib Prime.eq_two_or_odd'），0 sorry。

**④ ★共享基点：2（PROVED）**——★核心：奇偶性与素数共享基点 = 2——模 2 折叠的周期 = 素数域的唯一例外 = 临界线圆上的点。论证: (1) 奇偶性侧：2 槽环的周期 = 2（R141：模 2 折叠由 2 定义）——奇偶性的结构常数是 2; (2) 素数侧：2 是唯一偶素数（two_unique_even_prime）——素数的奇偶性例外点是 2; (3) 几何侧：2 在临界线圆上（R145 critical_circle_points：‖2-1‖ = 1）——2 是框架的几何点; (4) ★二者在 2 处交汇：奇偶性的周期（模 2）= 素数域的唯一例外 = 共享基点。形式化：`two_shared_basepoint`（锚定 two_unique_even_prime + R145），0 sorry。

**⑤ 全景（组合定理）**——★核心：偶数 = 对称对还原 ∧ 奇数 = 对称对 + 1 ∧ 2 在临界线圆上——奇偶性（模 2 折叠）观测素数：素数集合坍缩到 {2} ∪ {奇数}，★共享基点 = 2。形式化：`parity_prime_perspective`，0 sorry（合取项分别锚 even_is_symmetric_pair / odd_is_symmetric_pair_plus_one / R145）。
