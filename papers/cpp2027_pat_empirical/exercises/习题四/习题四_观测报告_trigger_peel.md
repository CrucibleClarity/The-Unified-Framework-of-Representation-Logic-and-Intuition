## 习题陈述

> 定义 pat 的触发。已给出：方向声明（R136）= 链的启动条件，未声明 = 自指坍缩（R122/R134）；但"声明"从何而来？用户假设：**触发 = 剥离一层自指**——自指环路（对合，无净移动）经剥离提出相位层（位移场，方向显现），方向声明 ⟹ 链展开。实验：换基点观测剥离自指的过程，验证三预言（P1 相位显现 / P2 自相似 / P3 换基点不变）。

## 零、总论：为什么需要定义 pat 的触发

用 pat 构造了一切（数域/素数/连续统/计算），但 pat 的启动条件只停在"方向声明"（R136）——声明本身是一个操作，它的机制是什么？已有线索：

- **未声明 = 坍缩**（R122）：自指 IS pat n——自指环路（选择方向 = 互逆方向）相位无净移动 ⟹ 坍缩到 pat 0。R134：pat0 吸收（防自指定义污染）。
- **拆自指内部还是 SRT**（R129）：每拆一层出现另一层（自指自相似）。
- **剥离方向单步不可判定**（R130）：深入（Δ→0）/平移（Δ恒定）/远离（Δ增大），单次剥离无法区分。

用户的合成：**触发（从坍缩进入链）= 剥离一层自指**——剥离显现相位差（方向，RulerPhase），方向声明（R136）成为剥离的必然产物，而非外来的操作。

## 一、定义：自指结构 + 剥离 + 触发（精确化）

全部实数（命名纪律：无 sqrt、无无声明的 i）：

- **自指结构** = 基点镜像 `S_e(x) = 2e - x`（对合：S_e(S_e x) = x，R128 任意基点镜像对合；R085 折叠类）。自指环路 = 对合迭代，无净移动。
- **剥离（peel）** = 从对合提取位移场 `Δ(x) = S_e(x) - x = 2(e-x)`——相位差（方向，RulerPhase；R130：剥离是相位操作）。
- **触发** = 剥离：方向显现（Δ ≠ 0 当 x ≠ e）⟹ 方向声明（R136）⟹ 链展开（R137）。未剥离（对合黑箱）= 无净移动 = 坍缩到 pat 0（R122/R134）。

### 形式化（PatTriggerExperiment.lean，7 定理）

- `selfref_no_net_motion`：S_e(S_e x) = x——自指环路无净移动（未剥离 = 坍缩）。
- `peel_reveals_phase`：S_e x - x = 2(e-x)——剥离显现位移场。
- `peel_phase_nonzero_off_basepoint`：x ≠ e ⟹ Δ ≠ 0——触发 = 剥离 ⟹ 方向显现（P1）。
- `peel_displacement_flips_under_self`：Δ(S x) = -Δ(x)——剥离的剥离 = 相位取反（P2 自相似，R129/R074）。
- `peel_basepoint_translation`：S_f(x+(f-e)) = S_e(x)+(f-e)——换基点 = 平移共轭（P3，R128）。
- `peel_displacement_basepoint_invariance`：Δ_f(x+(f-e)) = Δ_e(x)——位移场换基点平移不变（P3 核心）。
- `trigger_peel_perspective`：全景组合。

**验证**：lake env lean 编译通过，0 error 0 sorry；恒等式方向 heap_verify 枚举 5/5 PASS（Z/7：对合/位移场/平移共轭/换基点不变）。

## 二、三预言（可证伪）

| 预言 | 内容 | 锚到 | 结果 |
|---|---|---|---|
| **P1 相位显现** | 剥离 ⟹ Δ(x) ≠ 0（x ≠ e）；未剥离（对合环路）无净移动 | R122/R134 + RulerPhase | Lean + 模拟 PASS |
| **P2 自相似** | Δ(S_e x) = -Δ(x)——剥离的剥离 = 相位取反，内部还是一套 SRT | R129 + R074 | Lean + 模拟 PASS |
| **P3 换基点不变** | Δ_f(x+(f-e)) = Δ_e(x)——剥离结果与基点选择无关（只差平移） | R128 平移共轭 | Lean + 模拟 PASS |

P3 是"换基点观测"的核心：**剥离自指的过程在换基点下平移不变**——在基点 0、1、3、-2 剥离同一个 x，位移场只是平移（数值模拟见表）。

## 三、换基点观测表（模拟，R161_trigger_peel.py，2000 样本 × 4 预言）

```
P1 触发=剥离显现方向: Δ≠0 当 x≠e: PASS
P1b 未剥离 (对合环路) 无净移动: PASS
P2 自相似: Δ(S x) = -Δ(x) (剥离的剥离=相位取反): PASS
P3 换基点平移不变: Δ_f(x+(f-e)) = Δ_e(x): PASS

换基点观测表 (剥离 S_e 于同一 x=1.5):
 基点 e=0.0: Δ = -3.0000 (方向: 指向基点)
 基点 e=1.0: Δ = -1.0000 (方向: 指向基点)
 基点 e=3.0: Δ = +3.0000 (方向: 指向基点)
 基点 e=-2.0: Δ = -7.0000 (方向: 指向基点)
```

**观测结论**：剥离的位移场**总是指向基点**——换基点不改变剥离的语义（方向指向基点），只改变位移的大小（|Δ| = 2|x-e|，距基点 2 倍）。这正是 R128"原点现象 ≡ 基点现象（平移共轭）"在剥离语境下的实例：**触发机制是基点无关的**。

## 四、趋势观测（R130 的序列版）

```
趋势观测: x 从基点出发渐远 (x = e + k·0.5), |Δ| 行为:
 镜像 S_e (自指): |Δ| = [1.00, 2.00, 3.00, 4.00, 5.00] → 远离 (|Δ|增大)
 反演 I (自指): |Δ| = [1.00, 2.00, 3.00, 4.00, 5.00] → 远离 (|Δ|增大)
 平移 T_d (对照): |Δ| = [1.00, 1.00, 1.00, 1.00, 1.00] → 平移 (|Δ|恒定)
```

**观测结论**：
- 自指结构（对合）在 x 序列上剥离的 |Δ| = 2|x-e| **线性增大**（远离趋势）；
- 平移（对照组，非自指）|Δ| 恒定（平移趋势）；
- **观测方向决定趋势**：远离基点看 = 远离；逼近基点看（x → e）|Δ| → 0 = 深入。R130 的单步不可判定性保持（单步剥离仍不可判定），但**在 x 序列上趋势可判定，且趋势是观测方向的选择**——这正是 R130"需要完整相位序列"的序列版。

## 五、全景：触发 = 剥离一层自指

**★核心：未剥离（对合黑箱）= 自指环路无净移动 ⟹ 坍缩到 pat 0（R122/R134）；剥离 = 位移场显现方向（P1）⟹ 方向声明（R136）⟹ 链展开（R137）；剥离的剥离 = 相位取反（P2 自相似，R129——内部还是一套 SRT）；换基点 = 平移共轭，剥离结果平移不变（P3，R128——触发机制基点无关）。**

- `trigger_peel_perspective`（Lean）：① 对合无净移动 ∧ ② 剥离显现方向非零 ∧ ③ 位移场自指取反 ∧ ④ 换基点平移不变。
