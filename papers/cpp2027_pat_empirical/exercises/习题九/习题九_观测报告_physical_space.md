## 一、★五大力共享互锁对单元（问题①）

**★核心：五大力共享同一个基本单元——互锁对 {d, -d}：exp(iθ)·exp(-iθ) = 1。**

### 论证

1. **互锁对 = 力的基本单元**（R136 ②③：方向必须成对声明；R138：相位差可加；R143：对称对还原到 1）：exp(iθ)·exp(-iθ) = 1（R161 pair_interlock_self_consistent）。
2. **五大力的共享结构**：
 - 力学：作用-反作用成对（F + (-F) = 0，R164 action_reaction_pair）
 - 量子：4 互锁 = S³ = SU(2)（R149/R154）
 - 电磁：E⊥B 正交（R047）
 - 强弱：规范群 k 对（R161）
 - 引力：脱离对逐对独立（R161）
3. **共享单元**：每个力的动力学结构单元都是互锁对——成对的方向 {d, -d}，组合还原（R143）。力 = 互锁对的破缺/组合/投影。

### 形式化（PatPhysicalSpaceStructure.lean，1 定理）

- `forces_share_interlock_pair`：exp(iθ)·exp(-iθ) = 1——五大力共享互锁对单元。

**验证**：0 sorry。锚定 R161 pair_interlock_self_consistent。

## 二、★丢失结构的可观测性（问题②）

**★核心：一对互锁脱离物理空间后，剩余对仍互锁（物理法则保持）；脱离对的模长 ‖ρ(g)‖ = 1 是脱离后仍可观测的不变量。**

### 论证

1. **脱离保持互锁**（R161 pair_detachment_general：逐对独立）：一对互锁脱离物理空间（高维方向），剩余对仍互锁——**物理空间丢失结构后，剩余部分遵守物理空间法则**。
2. **单位圆模长 = 脱离不变观测**（R165 phaseRep_on_circle/R141）：‖exp(iθ)‖ = 1 对任意相位成立——脱离物理空间的对，其表示模长不随脱离改变，是**脱离后仍可观测的数据**（丢失结构的可观测印记）。
3. **丢失 → 可观测的机制**：脱离对进入高维（不可直接观测其相位 θ），但其单位圆模长（=1）与剩余对的互锁不变量仍可观测——物理空间通过剩余结构"感知"丢失结构的存在（如引力 = 脱离对的耦合效应，R164 CONJECTURE）。

### 形式化（PatPhysicalSpaceStructure.lean，2 定理）

- `detachment_keeps_observable`：脱离某些对，剩余对仍互锁（逐对独立）。
- `unit_circle_observable`：‖exp(iθ)‖ = 1——脱离不变的单位圆模长观测。

**验证**：0 sorry。锚定 R161 / R165 phaseRep_on_circle。

## 三、★物理空间结构猜测（问题③，CONJECTURE）

**★核心：物理空间 = 3 对共享互锁 = 3 节点 K3 完全图（3 边全互锁）= 3 维；可能收缩时间（R147 对合）与引力高维方向（R164 脱离对）。**

### 论证

1. **节点 = 3，边 = 3，全互锁**（R163：三体 = 3 节点全连接 = 三角形 = K3 完全图，每对共享 2 相位 = 6 互锁）——物理空间的 3 个独立方向两两全互锁。
2. **维度 = 3**（R161：3 对独立互锁 = 3 个方向自由度 = 6 相位 = ±x, ±y, ±z）——物理空间是 3 维。
3. **可能收缩的维度**：
 - **时间**（R147：时间 = 对合对称对，未来/过去成对）——时间对可收缩（时间不是空间维度，但可观测其"相位"→ 因果/熵）
 - **引力高维方向**（R164：引力 = 脱离投影，脱离对 = 高维方向）——引力对应的对已脱离物理空间
 - **完整结构可能 4 对**（3 空间 + 1 时间/引力），物理空间收缩到 3 对（3 维）。
4. **诚实边界**：这是结构猜测（CONJECTURE），依据 R161/R163/R164/R147——"物理空间 = 3 对 K3 全互锁 3 维"是观测归纳，非证明。

### 形式化（PatPhysicalSpaceStructure.lean，3 定理）

- `physical_space_three_pairs`：3 对独立互锁自洽（3 节点，CONJECTURE 依据）。
- `physical_space_K3_complete`：K3 完全图（3 节点 3 边全互锁，R163 三体结构）。
- `physical_space_structure_perspective`：★全景——3 对共享互锁 ∧ K3 全互锁。

**验证**：0 sorry。锚定 R161 three_independent_pairs_interlock / R163 three_body_six_shared_interlock。
