## 研究动机：从习题九的三个问题到精细化

习题九（R166）观测了物理空间的互锁结构：① 五大力共享互锁对单元 {d, -d}；② 丢失结构中发生可由物理空间观测的数据（脱离对单位圆模长 ‖ρ(g)‖ = 1）；③ 物理空间 = 3 对 K3 全互锁 3 维，可能收缩时间与引力高维方向。

## 一、观测主体 1：力学对称性精细化

### 1.1 惯性 = 基点 + 方向的锁定（无第三自由度）

习题七已观测：惯性 = 锁定方向链 x ↦ x+d 单射（R050/R137）。精细化：**匀速链由基点 x₀ 与方向 d 完全决定**——链 xₙ = x₀ + n·d 没有第三个自由度：

```
 x₀ x₁ x₂ x₃
 ──●──────────●──────────●──────────●──►
 ↑ ↑ ↑ ↑
 基点 x₀ x₀ + d x₀ + 2d x₀ + 3d
 整条链只由 (基点 x₀, 方向 d) 两个数据决定
```

定理 `uniform_chain_determined_by_basepoint_direction`：x₀ 与 d 完全决定整条链（∀ n, x n = x₀ + n·d）。

**对称性层面**：空间均匀（平移不变）+ 时间均匀（时间平移不变）⟹ 匀速直线——惯性 = 两个连续对称性（空间/时间平移）的交点。Pat 结构：方向 d 成对声明后（R136），链由 (基点, 方向) 唯一生成——与数域构造的"基点 + 方向声明"完全同构（R137: pat n = pat0 + n·d）。

### 1.2 力 = 脱锁（第二定律的 Pat 结构）

牛顿第二定律 a = F/m：加速度 = 偏离匀速链的度量。离散影子：**二次差分 ≠ 0 ⟺ 非匀速链**——力 = 锁定方向链的局部破缺：

```
匀速 (锁定): xₙ₊₂ - 2xₙ₊₁ + xₙ = 0 方向保持锁定
受力 (脱锁): xₙ₊₂ - 2xₙ₊₁ + xₙ ≠ 0 方向被扰动 = 力
```

定理 `acceleration_is_delocking`：二次差分非零 ⟹ 不存在 (x₀, d) 使链匀速——**力 = 链的脱锁**。

**对称性层面**：外力 = 平移对称性的破缺（有外力处"处处相同"失效）。Pat 结构：锁定 = 方向已声明；脱锁 = 方向被外部扰动——力学第二定律 = 锁定链的破缺动力学。

### 1.3 时间反演对称（无耗散）= 方向已成对

无耗散力学：t → -t 方程不变（时间反演对称）。离散影子：匀速链方向取反 d ↦ -d 后仍是匀速链——**时间反演 = 方向成对声明**（R136: {d, -d} 一次性声明）：

```
正向链: xₙ = x₀ + n·d 方向 d
反演链: xₙ = x₀ + n·(-d) 方向 -d, 仍是匀速链
```

定理 `time_reversal_preserves_uniform`：方向取反保持匀速律。

**对称性层面**：微观力学时间反演对称 = 时间方向已成对（未来/过去互逆, R147: 时间 = 对合对称对）——成对的方向无特权。

### 1.4 耗散破坏时间反演 = 单向方向 = 时间方向出现

含阻尼（每步速度损失 μ）的链：xₙ₊₁ - xₙ = d - μ（速度每步减少 μ）。其时间反演链的步长为 -(d - μ) = -d + μ（速度每步**增加** μ）——**反演链不满足同一律**：

```
正向 (耗散): 每步速度损失 μ ──►──►──►──► 越来越慢
反演 (看回): 每步速度增加 μ ◄──◄──◄──◄── 不是同一律
⟹ 时间反演对称被耗散破坏: 时间有了方向
```

定理 `dissipation_breaks_time_reversal`（d ≠ μ 时）：反演链步长 ≠ 正向链步长——耗散链时间反演不对称。

**对称性层面**：耗散 = 单向方向 = 未成对方向 = 时间方向出现（R147）。与实证对照：STDP（突触前后不对称）观测——**时间感知方向起源于不对称**（挂谷重述时感方向猜想）；训练实证——单向声明 = 特权 = 0/32（E12），成对声明 = 32/32。耗散是宏观力学中"单向方向"的唯一来源：无耗散力学时间对称，有耗散力学时间有方向。

## 二、观测主体 2：引力的对称方向在哪里

### 2.1 引力 = 四大基本力中唯一的单向力

引力相互作用方向**只有吸引**，无排斥对偶。1D 线性化模型（仅保留方向结构，F₁₂ = G·m₁·m₂·(x₂-x₁)）：

```
 m₁ m₂
 ●───────────────●
 ←──F₁₂─── 引力互相指向 (等大反向, 第三定律)
```

定理 `gravity_one_directional_linear` / `gravity_one_directional_linear'`：正质量间引力总是指向对方（x₁ < x₂ ⟹ F₁₂ > 0 指向 x₂；反之指向 x₁）——**方向由相对位置唯一决定，无自由选择**。定理 `gravity_pair_equal_opposite`：等大反向（第三定律成对，R164 action_reaction_pair 同构）。

**四大基本力的方向性对比**：

| 力 | 荷 | 方向对 | Pat 结构 |
|---|---|---|---|
| 电磁 | ± 电荷 | 成对 ✓（正负电荷都存在） | charge_negation_involution |
| 弱 | 手性 | 单向（宇称不守恒） | 规范对增长（R161） |
| 强 | 三色 | 三态（颜色禁闭） | k 对互锁（R161） |
| 引力 | 质量恒正 | **无对 ✗（只吸引）** | mass_no_negation |

### 2.2 质量无对合 vs 电荷有对合

引力的单向性有代数根源：**电荷有对合（q ↦ -q 保持物理意义），质量无对合（-m 无物理意义）**：

```
电荷: q ↦ -q ↦ q 对合 ✓ (正负电荷都存在)
 +1e ↔ -1e 成对方向
质量: m > 0, -m 无物理意义 无对合 ✗ (负质量不存在)
 ────► 只吸引 单向方向
```

定理 `charge_negation_involution`（对合存在）∧ `mass_no_negation`（负质量不存在）——**引力的对称方向"无对"**。

### 2.3 引力结构层：坐标平移不变（无特权基点）

与作用层的单向性相反，引力的**结构对称性最高**：引力只依赖相对位置，坐标平移不改变任何物理——微分同胚不变性的代数影子：

定理 `gravity_translation_invariant`：F 在 x ↦ x+a 下不变——**结构层无特权基点**（任何坐标选择等价）。

### 2.4 等效原理：引力可被基点（参考系）选择局部吸收

等效原理：自由落体观测者测不到引力（局域惯性系）。代数影子：自由落体换到自由落体系后回到匀速——引力项被参考系选择对消：

定理 `free_fall_restores_uniform`：自由落体位移 + 反号引力项 = 匀速位移——**引力 = 局部可被基点吸收的效应**。

### 2.5 ★引力对称方向的观测结论

把结构层与作用层分开观测：

```
引力:
 结构层: 无特权方向 (微分同胚/坐标无关) ← 四大基本力中最"对称"
 作用层: 指向基点 (质量) 的单向吸引 ← 四大基本力中最"单向"
 ─────────────────────────────────────────────────────
 组合: 结构最对称 ∧ 方向最单向 — 独一无二
```

结合习题九（R166 ③, CONJECTURE）与 R164：**引力对应的互锁对已脱离物理空间（脱离对）**——脱离后剩余可观测效应 = 单向吸引（脱离对的残余投影）。这给出引力的两个特征的一体解释：

1. **引力只吸引**：脱离对留下的残余方向是单向的（无对可还原）；
2. **引力极弱**（10⁻³⁶）：脱离对的残余投影强度远小于在空间内的互锁对（电磁 10² 倍于引力）。

## 五、力学的高维正交结构：辛结构 = 复结构（每自由度 = 四相位互锁对）

**★观测结论：是——力学的高维正交关系统一在辛结构（相空间）里，而辛结构本质是复结构（J² = −I）。每个自由度 (q, p) 是一个复平面 = 一个四相位互锁对；n 个自由度 = n 个互锁对两两辛正交。**

### 5.1 辛矩阵 J² = −I：相空间 = 复结构

辛矩阵 J = [[0,−1],[1,0]]（旋转 90°）满足 **J² = −I**——与虚数单位 i² = −1 同构。相空间 (q₁,p₁,…,qₙ,pₙ) 是 ℂⁿ：每个自由度 (qᵢ, pᵢ) 是一个复平面。

```
J = [[0, -1], [1, 0]] 旋转 90°
J² = -I i² = -1 同构 ⟹ 相空间 = 复空间
z = q + ip 每个自由度 = 一个复平面
```

定理 `symplectic_complex_square`：J(J v) = −v。

### 5.2 四相位循环 = R149 四相位互锁

J⁴ = I：**q → p → −q → −p → q**——旋转 90° 四次回到自己。这正是 R149 四相位互锁（i 幂周期 i, −1, −i, 1）的力学实例：

```
 p (动量)
 ↑
−q ←──┼──→ q (位置)
 ↓
 −p
 每步 = 乘以 J = 旋转 90° = 换一个相位
 四步回到自己 = 四相位互锁闭合
```

定理 `symplectic_four_phase_cycle`：J⁴ v = v。

### 5.3 复结构正交：Jv ⊥ v（F⊥v 的结构根源）

复结构的正交性：**Jv ⊥ v**——旋转 90° 即正交。圆周运动中半径方向与切向方向正好差一个 J：

```
r = (cos t, sin t) 半径方向
v = J·r = (−sin, cos) 切向 (差一个 J = 旋转 90°)
F = −mω²r 向心力 (沿半径)
F ⊥ v ⟺ Jv ⊥ v ← 力学正交性的根源
```

定理 `complex_structure_orthogonal`：Jv·v = 0。

### 5.4 辛正交：自由度间正交，自由度内配对

辛内积 ω((q₁,p₁),(q₂,p₂)) = q₁p₂ − p₁q₂：

```
不同自由度: ω((q₁,0),(q₂,0)) = 0 位置-位置正交 (symplectic_orthogonal_positions)
 ω((0,p₁),(0,p₂)) = 0 动量-动量正交 (symplectic_orthogonal_momenta)
同自由度: ω((q,0),(0,p)) ≠ 0 位置-动量配对 (共轭对 = 互锁对的配对,
 symplectic_pairing_nonzero)
```

**n 个自由度 = n 个互锁对，对与对两两正交**——高维正交结构的精确形态。

### 5.5 能量 = 相空间复模长（能量守恒 = 旋转不变）

谐振子能量 E = ½(p² + ω²q²) = ½ω²·(q² + (p/ω)²) = ½ω²·|z|²，其中 z = q + ip/ω：

```
E = ½ω²·|z|² 能量 = 复平面上的"半径²"
能量守恒 = 复模长不变 = 复平面旋转不变 (J 旋转下不变)
```

定理 `oscillator_energy_is_phase_radius`——**能量守恒的 Pat 结构 = 四相位互锁的旋转不变性**（与 R149 单位圆模长 ‖exp(iθ)‖ = 1 同构）。

### 5.6 各正交关系都是这一结构的投影

| 力学正交关系 | 高维结构中的投影 |
|---|---|
| F ⊥ v（向心力不做功） | 复平面内半径 ⊥ 切向（Jv ⊥ v） |
