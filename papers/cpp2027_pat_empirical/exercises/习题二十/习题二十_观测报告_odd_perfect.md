## 习题陈述

> 奇完全数（经典）：奇数 n 满足 σ(n) = 2n（σ = 约数和函数）。已知偶完全数 = 2^(p-1)·(2^p - 1)（Euclid-Euler）；奇完全数是否存在**未解**。唯一论点：**σ = 素因子展开（rad 的对偶）——σ₁(p^k) 奇 ⟺ k 偶（σ 奇偶性折叠）；完全数 = σ 加倍（对称对还原）；★奇完全数 ⟹ n 非平方（至少一个奇指数素因子，欧拉必要条件 q^α 的 pat 侧）；存在性 = CONJECTURE/OPEN。**

---

## 零、总论：σ = 素因子展开（rad 的对偶）

R179 建立了 rad = 素因子折叠（重数折叠到方向，rad(p^k) = p）。σ（约数和）是它的**对偶展开**：

```
rad(2³) = 2 （折叠重数到方向）
σ(2³) = 1+2+4+8 = 15 （展开重数到和）
```

**rad 丢弃重数（折叠到方向），σ 累加重数（展开到和）——素因子重数折叠的两端。** 完全数 σ(n) = 2n 是"展开后的约数和还原到加倍"。

## 一、★σ₁(p^k) 奇偶性折叠（PROVED）

**★核心：p 奇 ⟹ σ₁(p^k) = 1 + p + ... + p^k（k+1 个奇数项）⟹ σ₁(p^k) 奇 ⟺ k+1 奇 ⟺ k 偶——σ 的奇偶性 = 指数 k 的奇偶性投影（R171 奇偶性折叠在约数和上的投影）。**

### 论证

1. **σ₁(p^k) = 1 + p + ... + p^k**（mathlib sigma_one_apply_prime_pow）——k+1 项。
2. p 奇 ⟹ 每项 p^i 是奇数（奇数幂仍奇）——奇数项之和的奇偶性 = 项数奇偶性。
3. **σ₁(p^k) 奇 ⟺ k+1 奇 ⟺ k 偶**——σ 奇偶性 = 指数奇偶性折叠。

### 形式化（PatOddPerfect.lean，1 定理）

- `sigma_prime_pow_parity`：Odd (σ 1 (p^k)) ↔ Even k——★σ₁(p^k) 奇偶性折叠。

**验证**：0 sorry。锚定 sigma_one_apply_prime_pow + 奇数项求和奇偶性。

## 二、完全数 = σ 加倍（对称对还原）（PROVED）

**★核心：σ(n) = 2n ⟺ σ(n) - n = n——约数和还原到 2n（加倍 = 对称对还原 2n = n + n，R170/R085）。**

### 论证

1. σ(n) = 2n 等价于 σ(n) - n = n——约数和还原到 2n。
2. R170 哥德巴赫对称对：2n = n + n 是对称对还原（R085 折叠类）。

### 形式化（PatOddPerfect.lean，1 定理）

- `perfect_sigma_double_iff`：σ 1 n = 2 * n ↔ σ 1 n - n = n——完全数 = σ 加倍。

**验证**：0 sorry。ring/omega。

## 三、★奇完全数 ⟹ n 非平方（PROVED）

**★核心：σ(n) = 2n 偶；若 n 是平方（所有素因子指数偶）→ σ(n) 奇（可乘性 + 每个 σ(p^偶) 奇）→ 矛盾——奇完全数至少有奇指数素因子。**

### 论证

1. n 奇完全 ⟹ σ(n) = 2n 偶。
2. 若 n = m²：所有素因子指数偶（m² 的 factorization 指数 = 2·m 的指数）→ 每个 σ(p^偶) 奇（第一节 σ 奇偶性折叠）→ σ(n) = ∏σ(p^指数) 奇（奇数之积奇）。
3. σ(n) 奇 ∧ σ(n) 偶 矛盾——**n 非平方**。

### 形式化（PatOddPerfect.lean，2 定理）

- `odd_perfect_not_square`：奇数 n，σ(n) = 2n ⟹ ¬ IsSquare n——★奇完全数非平方。
- `odd_perfect_has_odd_exponent_prime`：⟹ ∃ p，p | n ∧ Odd (n.factorization p)——存在奇指数素因子（欧拉必要条件 q^α 的 pat 奇偶性侧）。

**验证**：0 sorry。锚定 σ 可乘性（isMultiplicative_sigma）+ 第一节奇偶性折叠。

## 四、全景（组合定理）

**★核心：σ₁(p^2) 奇 ∧ σ₁(p^1) 偶——σ 奇偶性折叠的实例（偶指数 → σ 奇，奇指数 → σ 偶）。**

### 形式化（PatOddPerfect.lean，1 定理）

- `odd_perfect_pat_perspective`：Odd (σ 1 (p^2)) ∧ Even (σ 1 (p^1))——全景。

**验证**：0 sorry。合取项锚第一节 sigma_prime_pow_parity。
