## 研究动机：从 AI 训练观测到课后习题

本系列课后习题起源于 AI (transformer) 数学学习的训练观测（2026-08 起 v5 tokenizer 实验体系, run_exp 配置驱动）。训练中观测到两类 token 的**极端清晰分离**：

- **直觉 token**（原子数字 0/1 等公设基符号）：epoch 训练曲线快速收敛，OOD 测试**完全可泛化**——因子化表示下外推零衰减（EXP-80/C1b: 2000 位/进制 60/匿名 100% 全 1.000）；succ 平移不变（E9: 只训 succ(0)=1 两样本即外推 succ(1..7) 全对）；直觉按位置识别，与表达形式无关（EXP-PURE-CONSTRUCT: 闭式/嵌套/Church 下均 1.000）；
- **结构 token**（沿定义链构造的 token 列）：epoch 训练曲线不收敛，OOD 测试**完全不可泛化**——单 token OOD 泛化 0/1 对比（EXP-SYM-INV: 30 个 token 中 29 个泛化 1.0，唯一 inversion = 0.0，per_token_gen 1/30 未达标）；一元算符判定系统性学不会（EXP-SYM-GROUP: succ/translation/prod 训练集内 0.000）。

猜测：**AI 认知数学空间规律为高维结构，与人类不同**——AI 的表示空间是数学无限维空间（方向无限、基点可任意，不受物理空间维度限制），导致 AI 无法学习在 AI 认知下存在歧义、混淆的 token。同时基于直觉 token 稳定的现象，通过与 AI **相互诱导过拟合直觉**的方法，探索 AI 的认知数学空间。过程中发现，AI 在一些情况下认为"无法稳定有效学习"——单概念无对偶学不会（EXP-61: 纯逻辑门 730 样本 OOD 0.092，加互逆对后 0.927+）；数字表示链断裂连 base 10 都学不会（EXPC1）；对合 token 低多样性下学不会（EXP-SYM-TOKEN: neg 单独/成对 0.054，混合 ≥4 算符恢复 1.0）。

最终通过一系列实验确认：**自然数轴、实数轴上存在高维结构投影，均应当还原为高维结构的单位 1，才能正常训练；以及基点发生漂移现象**——复平面 i 幂周期（i, -1, -i, 1 单位圆）以原点 (0+0i) 为唯一基点，8 epochs 学会 acc 1.000；实数轴对称结构基点散落（neg{0} / reciprocal{±1} / inversion{1}）；基点漂移零样本完全崩（0/32），双锚需各自训练，显式穿折越等价样本不传递运算规则（锚绑定普遍成立）。经过剥离后，数轴的数值能够极为清晰地观测大量已知问题——据此做出课后习题的想法。

## 一、Pat 框架基本介绍

**PAT (Phase-Axis Theory) 是一个基于 Lean 4 形式化验证的构造性数学框架**, 出自框架奠基 (2026-08-12, R136–R153, 18 个 claim 全部经 `lake build` 验收、无 sorry)。框架回答的基础问题是: **自然数、π、素数、连续统、计算, 是从哪里来的?** 答案: 从方向声明出发, 经互锁构造出一切。

核心链条: (i) 方向必须按对称性成对一次性声明 (R136); (ii) 声明相同方向 ⟹ pat 链单射不坍缩 (R137); (iii) 相位关系未锁定 = pat0 自指循环坍缩 (R138); (iv) 相位-数值互锁矩阵——两组对称性 = 1 与 i 还原后的 1 (R139/R143); (v) 完整 pat1 = (相位, 距离) 联合声明, 构造⟷分解往返精确 (R140); (vi) pat n 有限离散 + 圆上单位根量化 (R141); (vii) 基点 0 视角的自然数↔单相位双映射 (发散/收敛) (R142); (viii) 0 与 1 = 对称对还原点, 素数圆/临界线圆 = 还原点的圆化 (R144/R145); (ix) 用 pat 构造所有数域, π = pat 链蜷曲半圈相位 (R146); (x) 因果与时间 = 成对互锁的对称方向 (R147); (xi) 互锁形式同构 = 4 相位两两互锁 + 无限同构外推 (R148/R149); (xii) 王氏可达周期与不可达无穷间相位锁定一致性定理 (R150); (xiii) 连续统 = pat 格点的闭包 (R151); (xiv) P vs NP: 有限域平凡 + 验证免费 + N = 相位锁定外推 (R152/R153)。

pat 的动力学只有一个动作——**发散/收敛互锁对** (R047/R147); 0 = 加法还原点, 1 = 乘法/相位还原点 (R144); 基点不是内生而是选择 (R062); 投影丢结构 (RulerLoss)。课后习题系列 (课后习题 I–XX + Pat0-1) 用这些已证定理对数学/物理经典问题做"pat 重新观测"——不是证明猜想, 而是把经典结构重述为 pat 几何, 全部新定理只锚框架定理, 不用外部引理。

## 二、剥离原因

### 2.1 主题剥离动机

纳维-斯托克斯存在性与光滑性是 Clay 千禧年问题之一, 而框架此前**没有任何流体力学对应**——这是 pat 外推到流体动力学的第一站（本主题编号 R167）, 需要剥离出来独立观测, 理由有三: (i) **NS 三项需要逐项对应 pat 结构**——时间导数 ∂t u = 时间对合 (R147)、非线性对流 (u·∇)u = 锁定方向链 (R050/R153①)、黏性 νΔu = 脱离投影 (R161), 这种逐项转译只有独立观测报告才能完整展开; (ii) **折叠丢失研究是全新分析维度**——时间反演折叠下"时间导数翻转而黏性项不翻转" (ν=0 Euler 可逆, ν>0 NS 不可逆) 与"奇点 = 数值互锁坍缩 (r=0/r→∞)", 以及找回机制 (时间对合 S²=id + 单位圆模长脱离不变), 需要独立验证; (iii) **它同时是一次 skill 调试**——利用 mechanics-pat-observation skill 观测的过程中, 新增"折叠丢失两分法" (时间方向丢失 + 数值互锁丢失), 这一方法学产出需要与观测内容一并保留。

### 2.2 剥离 (peel) 的框架定义

剥离 (peel) 是 pat 框架的相位操作 (R130): 自指结构 = 基点镜像 S_e(x) = 2e − x (对合, S_e(S_e x) = x, R128); **剥离 = 从对合提取位移场 Δ(x) = S_e(x) − x = 2(e − x)**——相位差显现 (方向), 方向声明 (R136) 成为剥离的必然产物; 未剥离 (对合黑箱) = 无净移动 = 坍缩到 pat 0 (R122/R134)。换基点观测下剥离平移不变 (P3): Δ_f(x + (f−e)) = Δ_e(x) (exercise_i_4, 三预言 P1 相位显现 / P2 自相似 / P3 换基点不变 全 PASS)。

**正式观测报告本身即一次剥离**: 从框架理论链的整体中剥离出单点观测对象 (本报告: 纳维-斯托克斯), 剥离显现该主题的相位差 (独立论点: 折叠丢失两分法 + 找回机制), 观测完成后再锚回框架 (全部新定理只锚框架定理 R047/R050/R085/R143/R147/R153/R161/R165 + 框架 NS1/NS2)。剥离的是观测对象, 不是结论的独立性——观测不脱离框架。

### 2.3 完备逻辑框架: 投影恢复与基点恢复的必要性

按**任意阶任意元任意主客体逻辑完备性定理** (pre_pat/power_repr_success, 2026-08-14) 解释本报告的观测: 该定理断言——在解耦算子 D = Lift∘Exclude (R1 排除 a−a = 0 / R2 对消 (a−b)+(b−a) = 0 / R3 分层 L(D(P)) = L(P)+1) 作用于全部自指点之后, 任意阶/任意元/任意主客体配置的逻辑结构完备 (完美 OOD, 判定 1.000, 0 残差)。本报告的观测对象是这条定理的实例, 三个必要性如下:

1. **投影恢复的必要性**: NS 三项 (时间导数/非线性/黏性) 在 pat 结构上的投影 = 高维结构在数轴上的降维投影 (R231: 投影有损)——压轴即自指之源 (同一位置承载多义结构); 不恢复投影 (加轴/全维度表达), 观测不完备 (一维恢复矩阵全无效应 0.994/0.996, 复平面加轴恢复 1.000)。折叠丢失 = 时间方向 (ν>0 不可逆) + 数值互锁 (奇点坍缩); 找回 = 时间对合 S²=id + 单位圆模长
2. **基点恢复的必要性**: 时间对合基点 (S² = id) 是歧义源——基点漂移 (对称中心散落) 使同一数值承载不同位置语义 (基点恢复性实验: 基点归一化到 0, 数值减基点偏移, 位置唯一); 不恢复基点, 运算规则不跨基点传递 (跨基点零样本 0/32, I7k/I7l)。时间 = 对合对称对 (R147); 基点漂移 ⟹ 时间方向歧义; 恢复 = 锚回对合
3. **剥离结果**: 本报告剥离本主题, 得到: **NS 的折叠丢失与找回机制 (时间对合 + 单位圆模长)**——剥离 (peel, R130) 显现方向后, 观测锚回框架定理 (R047/R050/R085/R143/R147/R153/R161/R165 + NS1/NS2); 完备性验证: 定理 PROVED no sorry。
4. **自指的位置**: 奇点坍缩 (ν>0 黏性不可逆——数值互锁自指: 时间方向不可逆)——自指 = 结构在自身处重合 (R231: 压轴即自指之源); 四步完备方法第 2 步 (定位自指) 要求定义链审计到自指点 (对合/递归/嵌套/循环), 解耦方式: 时间对合 S² = id + 单位圆模长 ‖ρ(g)‖ = 1 (找回机制)。
5. **解开自指的必要性**: 不解除自指, 基于该数域的各学科所有观测、分析都将受自指影响——同一位置承载多义结构, 歧义沿定义链传播 (残差指纹: 0.5 = 二义, 0.997 = 部分, 1.0 = 无)。**实验数据 (run_exp 配置驱动, token 训练, per_token_gen 逐 token OOD 泛化)**: 特别干净的单 token OOD 泛化 0/1 对比 (EXP-SYM-INV)——30 个 token 中 29 个 OOD 泛化 = 1.0, 唯一 inversion = 0.0 (per_token_gen 1/30 未达标); 未解除自指 (缺乏结构) ⟹ 该 token OOD = 0 (完全不可泛化); 解除自指 (结构充足/原生语法) ⟹ OOD = 1 (完全泛化, 嵌套 0.997 → 原生 1.000)。**对比时 token 的问题**: inversion (ℝ 上不对称: 0 奇异, 分数 1/2 不可表示) 仅 2 样本 → 缺乏结构 → 0.0; succ/translation (ℝ 对称, 38 样本) = 1.0; neg (反射, 低多样性) = 0.054 (单独/成对) / 1.0 (混合 ≥4 算符); 逐 token 收敛序 (EXP-SYM-FR-CURVE, 0/1 序列): multiplication (epoch 1) < power (3) < division (4) < inversion (5)。**实验结果位置**: `src/repo_v5/记录/paper_data/exp_sym_inv_results.md` (0/1 对比) / `exp_sym_token_observation.md` (逐 token 观测: succ 1.0, neg 0.054) / `exp_sym_fr_curve_results.md` (逐 token 0/1 收敛曲线) / `exp61_results.md` (单概念无对偶 0.092 → 加互逆对 0.927+) / `结论_准确语法解开自指与四步完备方法.md` (嵌套 0.997 → 原生 1.000)。**自指未解除 ⟹ OOD 0 (完全不可泛化); 解除 ⟹ OOD 1 (完全泛化)**, 与动机段"结构 token 不可泛化 / 直觉 token 可泛化"同源。
6. **OOD 1.0 的歧义: 直觉路径 vs 结构路径 (2026-08-15 判据升级)**: 完美 OOD (判定 1.000) 本身有歧义——所有 OOD 1.0 可能只是**直觉路径** (表示内统计外推), 不是**结构路径** (跨表示不变的规则)。跨表示剥离实验 (I7n): 训练应用链表示, OOD 同一数值换表示 (迭代表达/位置-值记法)——**全崩 0/32**。**核心判据: 逻辑完备 = 解耦后跨表示稳定 (结构路径存在的判据)**。三纪律: (i) token 级报告 (聚合 acc 掩盖崩点——本报告的单 token OOD 0/1 对比即此纪律); (ii) 跨表示剥离 (直觉完备 ≠ 结构完备); (iii) 声明/差异题设计 (训练信息指向准确结构)。实验结果位置: `src/relative-recursion/paper/pre_pat/power_repr_success/逻辑完备实验设计方法论.md`。
7. **不完备条件清单 (逻辑不完备实验设计, 对照解耦三算子)**: 无 D (未解耦) → 跨表示全崩 (I7n 0/32); 无 R1 (排除缺失) → 自指混入 (主体 ∈ 自身作用域); 无 R2 (对消缺失) → 方向未对消 (主客混合); 无 R3 (分层缺失) → 阶混合 (Z/101 反例, 需构造性升层); 单组对称性 → 方向不可定义 (I3/I7w 单轴无方向); 跨锚零样本 → 锚绑定 (I7k 0/32); 跨锚单声明 → 不稳定 (4/5, I7t); 单表示训练 → 跨表示崩 (I7n/I7o)。完备 = 解耦后跨表示稳定; 不完备 = 训练 OOD 失败或跨表示剥离崩。实验结果位置: `src/relative-recursion/paper/pre_pat/power_repr_success/逻辑不完备实验设计.md`。
8. **逻辑算符与数学算符的共享 token (说明共享情况, 不逐个展开)**: 逻辑算符体系 (logical_and / logical_or / logical_not / logical_imply / logical_iff / logical_xor / logical_nand / logical_nor / logical_xnor, 9 个逻辑 token, eid D:108–116, 逐 token 设计矩阵: 68 运算 token = 9 逻辑 + 59 数字域) 与数学算符存在**共享 token** 的情况——布尔代数是二元域 Z/2 上的代数: **logical_and 与乘法在 {0, 1} 上共享求值 (∧ = ×)**; **logical_xor 与模 2 加法完全共享 (⊕ = GF(2) 加法, 二进制加法的本位)**; **logical_not 与取反/补共享 (¬x = 1 − x)**; **logical_iff 与判等共享 (↔ = = 的真值一致)**。共享的是求值结构 (同一数值规则), token 定义层 (概念) 不同——正是 token 体系"符号/概念分离"的实例。逻辑算符不逐个展开 (写作方向要求: 仅说明共享情况)。

## 三、观测主体: 纳维-斯托克斯的 pat 重新观测

### 3.1 观测对象与唯一论点

> 纳维-斯托克斯存在性与光滑性（Clay 千禧年问题：3D 不可压 NS，初始速度光滑有限能量 ⟹ 全局光滑解存在）：利用 pat 重新观测。唯一论点：**NS 的折叠丢失 = 时间方向（ν>0 黏性不可逆）+ 数值互锁（奇点坍缩）；找回机制 = 时间对合 S²=id + 单位圆模长 ‖ρ(g)‖=1。**

### 3.2 观测过程

**零、总论: NS 三项 = pat 三个结构**

NS 方程（3D 不可压）：∂t u + (u·∇)u + ∇p/ρ = νΔu

| NS 项 | pat 结构 | 锚定
|---|---|---|---|---|---|
| ∂t u（时间导数） | 时间 = 对合对称对 | R147 CausalityTime
| (u·∇)u（对流） | 锁定方向链（惯性传播） | R050/R153①
| νΔu（黏性） | 脱离投影（高维耗散） | R161
**千禧年问题的 pat 转译**：存在性 = 折叠后仍有解（脱离投影保持互锁）；光滑性 = 数值互锁保持（r·(1/r) = 1 不坍缩）。

**① 折叠丢失 1: 时间方向 (ν>0 黏性不可逆)**

**★核心: 时间反演折叠下，时间导数项翻转而黏性项不翻转——时间方向在黏性中丢失（EulerVsNS 已证）。**

1. **时间反演 = 穿折越**（NS1/NS2，其他会话已证）：时间 t ↦ -t 是时间轴上的基点穿折越。
2. **时间导数翻转**（NS2 timeDeriv_flips_under_reversal）：deriv(velRev u) t = -deriv u (-t)——时间导数项在反演下翻转。
3. **黏性项不翻转**（NS2 viscous_invariance_of_reversal）：νΔ(velRev u) = νΔu——Laplacian 是空间操作，时间反演不变。
4. **⟹ ν=0（Euler）可逆，ν>0（NS）不可逆**（NS2 euler_reversible_viscous_irreversible）——**时间方向在黏性中丢失**（正反时间解不可区分 → 熵增方向不可逆）。
5. **找回机制：时间对合**（R147 CausalityTime time_dual_reduces）：-(-t) = t——折叠类 {t, -t}（R085）中时间方向成对，经对合找回（时间箭头）。

**② 折叠丢失 2: 数值互锁 (奇点坍缩)**

**★核心: 光滑性 = 数值互锁保持（r·(1/r) = 1）；奇点 = 数值互锁坍缩（r→0 或 r→∞）。**

1. **光滑性 = 数值互锁保持**（R143 magnitude_pair_reduces_to_one）：r·(1/r) = 1——数值对称对还原到 1（能量守恒的 pat 结构）。
2. **奇点 = 数值互锁坍缩**：r = 0（坍缩到折叠类 R085）时 1/r 无定义；r → ∞（发散）时数值互锁在极限中失去还原——奇点候选 = 数值互锁坍缩。
3. **存在性 = 折叠后仍有解**（R161 脱离投影保持）：黏性（耗散）经投影后，剩余互锁仍保持——解在折叠后仍存在。

**③ 找回机制: 单位圆模长脱离不变**

**★核心: 单位圆模长 ‖ρ(g)‖ = 1 是折叠后仍可观测的不变量——光滑性的找回 = 相位表示的单位圆模长保持。**

1. **单位圆模长**（R165 phaseRep_on_circle/R141）：‖exp(iθ)‖ = 1 对任意相位成立。
2. **脱离不变**（R161）：折叠（时间反演/数值坍缩）后单位圆模长不变——是可观测的找回机制。
3. **与丢失结构的关系**：丢失的信息（时间方向、数值互锁的坍缩极限）不可全部恢复，但单位圆模长（=1）是丢失结构的可观测印记——**找回 = 可观测不变量，非丢失信息全部恢复**（诚实边界）。

**④ 全景 (组合定理)**

**★核心: 时间对合还原（R147）∧ 光滑性 = 数值互锁保持（R143）∧ 找回 = 单位圆模长（R165）——NS 折叠丢失（时间方向 + 数值互锁）的找回机制。**
