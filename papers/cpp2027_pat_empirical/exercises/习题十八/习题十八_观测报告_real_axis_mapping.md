# 课后习题 XVIII：实数轴在 pat 上的映射架构图景

## 习题陈述

> 是否有可能，实数轴视角下丢失了某一个槽？唯一论点：**4 次单位根投影（R175）下，实数轴的不同子集覆盖不同槽位组合，每个子集都有 pat 上"永远不出现"的位置——素数缺 0 槽（+1，p ≡ 0 mod 4 是合数），考拉兹循环 {1,4,2} 缺 3 槽（-I，循环无 ≡ 3 mod 4 的数）。**

---

## 零、总论：映射架构图景

4 次单位根投影 n ↦ I^n（R175：奇偶 = 实/虚轴；R141：4 槽环）把实数轴上的点映射到 4 个槽位（n mod 4）：

| 实数轴子集 | 槽位 (n mod 4) | 缺失槽 |
|---|---|---|
| 自然数 ℕ | {0, 1, 2, 3} | 无（全覆盖） |
| 偶数 | {0, 2} | 实轴（R175） |
| 奇数 | {1, 3} | 虚轴（R175） |
| **素数** | {1, 2, 3} | **★0 槽（+1）** |
| **考拉兹循环 {1,4,2}** | {0, 1, 2} | **★3 槽（-I）** |

---

## 一、素数像永不落 0 槽（PROVED）

**★核心：p mod 4 = 0 ⟺ 4 | p ⟺ p = 4k（k ≥ 1）是合数——素数永不 ≡ 0 (mod 4)，I^p ≠ 1——pat 的 +1 位置是素数永远不出现的位置。**

### 论证

1. **素数永不 ≡ 0 (mod 4)**（`prime_mod_four_never_zero`）：p mod 4 = 0 ⟺ 4 | p ⟺ p = 4k（k ≥ 1）——4·1 = 4 非素数，4k > 4 时被 4 整除是合数——矛盾。
2. **I^p ≠ 1**（`prime_pow_I_never_one`）：I^p = 1 ⟺ 4 | p（I 是 4 次单位根，I^4 = 1）——由第 1 步素数永不落 0 槽，I^p ≠ 1。
3. **映射架构含义**：素数在 pat 上的像 = {I, -1, -I}，缺 0 槽（+1，实轴正侧）——素数是"缺一个槽"的实数轴子集。

### 形式化（PatRealAxisMapping.lean，2 定理）

- `prime_mod_four_never_zero`：素数 p ⟹ p mod 4 ≠ 0。
- `prime_pow_I_never_one`：素数 p ⟹ I^p ≠ 1。

**验证**：0 sorry。锚定 4 整除合数论证 + 4 次单位根性质。

## 二、考拉兹循环 {1,4,2} 像缺 3 槽（PROVED）

**★核心：1 ≡ 1，4 ≡ 0，2 ≡ 2 (mod 4)——循环中永不出现 ≡ 3 (mod 4) 的数，循环的 pat 像 {I, 1, -1} 缺 3 槽（-I，虚轴负侧）。**

### 论证

1. **循环槽位**（`collatz_cycle_mod_slots`）：1 % 4 = 1，4 % 4 = 0，2 % 4 = 2——循环相位 1 槽 → 0 槽 → 2 槽 → 1 槽。
2. **永不落 3 槽**（`collatz_cycle_pow_never_neg_I`）：I^1 = I ≠ -I，I^4 = 1 ≠ -I，I^2 = -1 ≠ -I——循环像无 -I。
3. **对偶**：素数缺 0 槽（+1），循环缺 3 槽（-I）——两个子集缺失不同的 pat 位置。

### 形式化（PatRealAxisMapping.lean，2 定理）

- `collatz_cycle_mod_slots`：1 % 4 = 1 ∧ 4 % 4 = 0 ∧ 2 % 4 = 2。
- `collatz_cycle_pow_never_neg_I`：I^1 ≠ -I ∧ I^4 ≠ -I ∧ I^2 ≠ -I。

**验证**：0 sorry。norm_num。

## 三、全景（组合定理）

**★核心：素数像永不落 0 槽（I^p ≠ 1）∧ 循环槽位 = {0,1,2} ∧ 循环像永不落 3 槽（无 -I）——映射架构图景：实数轴子集的像有结构性空缺。**

### 形式化（PatRealAxisMapping.lean，1 定理）

- `real_axis_pat_mapping_perspective`：素数缺 0 槽 ∧ 循环槽 {0,1,2} ∧ 循环缺 3 槽——全景。

**验证**：0 sorry。合取项分别锚第一、二节定理。

## 四、习题解答总结

| 论点 | 内容 | 锚定 | 标签 |

| 循环槽位 = {0,1,2} | 1,4,2 mod 4 | R176 | PROVED |

**习题的回答（一句话）**：**是的——实数轴的子集在 pat（4 次单位根投影）上各有结构性空缺：素数永远不落 0 槽（+1，因为 4k 是合数），考拉兹循环 {1,4,2} 永远不落 3 槽（-I，因为循环无 ≡ 3 mod 4 的数）——"实数轴视角下丢失的槽" = 子集在 pat 投影下的空缺槽位。**

**诚实边界**：结构观测（投影图景：槽位覆盖与缺失），非素数分布理论；缺失槽是对"子集像"的刻画，不是对实数轴本身的否定。
