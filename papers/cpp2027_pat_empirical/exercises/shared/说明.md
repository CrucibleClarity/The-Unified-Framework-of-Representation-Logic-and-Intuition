# shared/ — 共享基础设施（追加-only 稳定层）

> 本目录存放跨习题共享的基础设施，**不属任何单个习题**。契约：**只追加，不修改已有条目**——修改共享文件 = 破坏所有引用它的习题（破坏面 = N）；追加 = 破坏面 0。习题论文经 `../shared/` 固定路径引用。

---

## 文件清单

| 文件 | 内容 | 变更契约 |
|---|---|---|
| `对照说明.md` | 全字段引用清单（85+ 条，验证记录） | 只追加新条目，禁改/删已有条目 |

## 破坏面契约

```
// ==== 校验 (assert) ====
assert: 共享文件只追加 (append-only), 禁修改/删除已有条目
assert: 习题论文经固定路径 ../shared/ 引用, 禁路径幻觉 ("同目录" 但文件在别处)
assert: 单习题变更 (论文/定理/claim) 只动本习题目录 + claim + Lean 真源
assert: 共享层变更须先声明破坏面 (影响 N 个习题), 追加不影响已有
```

## 与习题的边界

- **共享层**（本目录）：引用清单——追加-only
- **习题层**（习题N）：论文 + 说明 + claim + Lean 真源——自维护
- **快照层**（../lean/）：构建仲裁器同步，勿手改
