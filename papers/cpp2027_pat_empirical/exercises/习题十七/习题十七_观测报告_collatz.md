## 习题陈述

> 考拉兹猜想（经典）：任意正整数 n 经迭代 f(n) = n/2（n 偶），3n+1（n 奇）最终到达 1。唯一论点：**考拉兹 = 奇偶性折叠驱动的轨道——偶数（0 槽）→ 取消一个 2 因子（n/2，折叠类还原）；奇数（1 槽）→ 3n+1 必落偶数槽（★奇数步必落偶数，轨道无连续奇数）；循环 1 → 4 → 2 → 1 = 奇偶偶 奇偶性折叠模式。★猜想 = 所有轨道最终落入奇偶偶 循环（CONJECTURE，未证）。**

---

## 零、总论：考拉兹 = 奇偶性折叠的轨道

考拉兹单步在 pat 里就是**奇偶性折叠（模 2 折叠，R171/R141 2 槽环）的决策**：

```
考拉兹单步 f(n):
 偶数 (0 槽, R171 even_two_slot) → n/2 = 取消一个 2 因子 (折叠类还原, R085)
 奇数 (1 槽, R171 odd_two_slot) → 3n+1 = ★必落偶数槽 (3·奇+1 = 偶)
```

轨道 = 奇偶性折叠驱动的收缩过程：偶数消 2 因子（可逆），奇数被强制推回偶数槽。

## 一、考拉兹单步 = 奇偶性折叠决策（PROVED）

**★核心：f(n) = n/2（偶）/ 3n+1（奇）是模 2 折叠的 0 槽/1 槽决策。**

### 论证

1. **偶数（0 槽）→ n/2**：2 槽环 0 槽（R171 even_two_slot），考拉兹步取消一个 2 因子 = 折叠类还原（R085；除以 2 幂 = 沿素数 2 折叠类下降，R097）。
2. **奇数（1 槽）→ 3n+1**：2 槽环 1 槽（R171 odd_two_slot）——★输出必为偶数（见第二节）。

### 形式化（PatCollatz.lean，3 定理）

- `collatzStep`：考拉兹单步（偶 → n/2，奇 → 3n+1）——折叠决策。
- `collatz_even_step`：Even n → collatzStep n = n/2（0 槽 → 消 2 因子）。
- `collatz_odd_step`：Odd n → collatzStep n = 3n+1（1 槽 → 3n+1）。

**验证**：0 sorry。锚定 R171 槽位 + if 分支。

## 二、★奇数步必落偶数槽（PROVED）

**★核心：3·奇 + 1 = 偶——考拉兹轨道中奇数后面永远是偶数（无连续奇数）。**

### 论证

1. **3·奇 = 奇**（奇 × 奇 = 奇），**奇 + 1 = 偶**。
2. 所以奇数步输出 3n+1 必为偶数——轨道奇偶性序列中奇数后必接偶数。
3. 这是奇偶性折叠（R171 坍缩）对轨道的结构约束：轨道奇偶模式 = 偶* 或 奇偶*。

### 形式化（PatCollatz.lean，1 定理）

- `collatz_odd_step_even`：Odd n → Even (3n+1)——★奇数步必落偶数槽。

**验证**：0 sorry。ring（3·奇+1 = 偶）。

## 三、偶数步还原（消 2 因子可逆）（PROVED）

**★核心：Even n → 2·(n/2) = n——除以 2 后乘 2 还原，折叠类下降可逆。**

### 论证

1. 偶数 n = 2k ⟹ (2k)/2 = k ⟹ 2·k = n。
2. 考拉兹偶数步 = 消一个 2 因子，可逆（R085 折叠类；R097 素数 2 幂链单相位）。

### 形式化（PatCollatz.lean，1 定理）

- `even_half_restore`：Even n → 2·(n/2) = n——消 2 因子可逆。

**验证**：0 sorry。Nat 除法引理。

## 四、奇数两步合并 = (3n+1)/2（PROVED）

**★核心：奇数步输出 3n+1 是偶数 → 下一步必除 2——奇数的有效推进 = 奇数 → (3n+1)/2。**

### 论证

1. 奇数步输出 3n+1 是偶数（第二节）→ 下一步必除 2。
2. 两步合并 = (3n+1)/2：中间偶数步只消因子 2——奇数推进的核心步。

### 形式化（PatCollatz.lean，1 定理）

- `collatz_odd_merged_step`：Odd n → collatzStep (collatzStep n) = (3n+1)/2——奇数两步合并。

**验证**：0 sorry。collatz_odd_step + collatz_even_step 组合。

## 五、循环 1 → 4 → 2 → 1（PROVED）

**★核心：1 奇 → 4 偶 → 2 偶 → 1——奇偶性模式 奇偶偶 循环（周期 3 的奇偶性折叠模式）。**

### 论证

1. f(1) = 3·1+1 = 4（奇数步）；f(4) = 4/2 = 2（偶数步）；f(2) = 2/2 = 1（偶数步）。
2. 奇偶性模式：奇 → 偶 → 偶 → 奇——周期 3 的折叠模式。
3. ★考拉兹猜想 = 所有轨道最终落入此循环（CONJECTURE）。

### 形式化（PatCollatz.lean，1 定理）

- `collatz_cycle_142`：collatzStep 1 = 4 ∧ collatzStep 4 = 2 ∧ collatzStep 2 = 1——循环 = 奇偶偶 模式。

**验证**：0 sorry。分支计算 + norm_num。
