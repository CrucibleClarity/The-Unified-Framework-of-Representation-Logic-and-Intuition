## 一、孪生素数对 = 对称对（R170/R085）

**★核心：(p, p+2) 关于中点 p+1 对称——孪生素数对 = 间隔 2 的素数对称对。**

### 论证

1. **对称对**（R170 哥德巴赫对称对 / R085 折叠类）：(p+2) - (p+1) = -(p - (p+1))——p 和 p+2 关于中点 p+1 对称（距离 ±1）。
2. **孪生素数对之和 = 偶数**：p + (p+2) = 2(p+1)——两个孪生素数的和是偶数（R170 哥德巴赫分解的特殊实例）。
3. **孪生素数对 = 哥德巴赫对称对的素数实例**。

### 形式化（PatTwinPrime.lean，2 定理）

- `twin_pair_symmetric`：(p+2) - (p+1) = -(p - (p+1))——孪生素数对 = 对称对。
- `twin_pair_sum_even`：p + (p+2) = 2(p+1)——孪生素数对之和 = 偶数。

**验证**：0 sorry。ring。

## 二、间隔 2 = 临界线圆直径 = 奇偶性折叠周期（R159/R171）

**★核心：间隔 2 是 pat 框架的"结构常数"——既是临界线圆直径（R159/R145），又是奇偶性折叠周期（R171）。**

### 论证

1. **间隔 2 = 临界线圆直径**（R159 twin_gap_is_circle_diameter / R145）：0, 2 ∈ 临界线圆（圆心 1 半径 1），互为直径端点（‖2-0‖ = 2）。
2. **间隔 2 = 奇偶性折叠周期**（R171 / R141）：模 2 折叠的周期 = 2（2 槽环 {0,1}；偶数 = 对称对还原 2n=n+n）——两个孪生素数间隔恰好一个折叠周期。
3. **间隔 2 是连接点**：临界线圆（黎曼侧）与奇偶性折叠（素数侧）在间隔 2 交汇。

### 形式化（PatTwinPrime.lean，2 定理）

- `twin_gap_circle_diameter`：‖2-1‖ = 1 ∧ ‖0-1‖ = 1 ∧ ‖2-0‖ = 2——间隔 2 = 临界线圆直径。
- `twin_gap_parity_period`：2n = n + n——间隔 2 = 奇偶性折叠周期。

**验证**：0 sorry。锚定 R145 critical_circle_points / R171 even_is_symmetric_pair。

## 三、孪生素数对都是奇数（R171 奇偶性坍缩）

**★核心：除 (2, 4) 外，孪生素数对 (p, p+2) 都是奇数——都在奇偶性投影的奇数侧。**

### 论证

1. **素数奇偶性坍缩**（R171 primes_parity_collapse）：素数 p ≠ 2 ⟹ Odd p。
2. **孪生素数对都在奇数侧**：p 和 p+2 都是奇数（间隔 2 = 奇偶性周期，两个奇数间隔一个折叠周期）。
3. **奇偶性视角**：孪生素数对是"奇数 + 奇数周期"结构。

### 形式化（PatTwinPrime.lean，1 定理）

- `twin_primes_odd`：Prime p ∧ Prime (p+2) ∧ p ≠ 2 ⟹ Odd p——孪生素数对都是奇数。

**验证**：0 sorry。锚定 R171 primes_parity_collapse。
