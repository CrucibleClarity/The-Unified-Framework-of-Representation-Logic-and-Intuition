## 研究动机：从 AI 训练观测到课后习题

本系列课后习题起源于 AI (transformer) 数学学习的训练观测（2026-08 起 v5 tokenizer 实验体系, run_exp 配置驱动）。训练中观测到两类 token 的**极端清晰分离**：

- **直觉 token**（原子数字 0/1 等公设基符号）：epoch 训练曲线快速收敛，OOD 测试**完全可泛化**——因子化表示下外推零衰减（EXP-80/C1b: 2000 位/进制 60/匿名 100% 全 1.000）；succ 平移不变（E9: 只训 succ(0)=1 两样本即外推 succ(1..7) 全对）；直觉按位置识别，与表达形式无关（EXP-PURE-CONSTRUCT: 闭式/嵌套/Church 下均 1.000）；
- **结构 token**（沿定义链构造的 token 列）：epoch 训练曲线不收敛，OOD 测试**完全不可泛化**——单 token OOD 泛化 0/1 对比（EXP-SYM-INV: 30 个 token 中 29 个泛化 1.0，唯一 inversion = 0.0，per_token_gen 1/30 未达标）；一元算符判定系统性学不会（EXP-SYM-GROUP: succ/translation/prod 训练集内 0.000）。

猜测：**AI 认知数学空间规律为高维结构，与人类不同**——AI 的表示空间是数学无限维空间（方向无限、基点可任意，不受物理空间维度限制），导致 AI 无法学习在 AI 认知下存在歧义、混淆的 token。同时基于直觉 token 稳定的现象，通过与 AI **相互诱导过拟合直觉**的方法，探索 AI 的认知数学空间。过程中发现，AI 在一些情况下认为"无法稳定有效学习"——单概念无对偶学不会（EXP-61: 纯逻辑门 730 样本 OOD 0.092，加互逆对后 0.927+）；数字表示链断裂连 base 10 都学不会（EXPC1）；对合 token 低多样性下学不会（EXP-SYM-TOKEN: neg 单独/成对 0.054，混合 ≥4 算符恢复 1.0）。

最终通过一系列实验确认：**自然数轴、实数轴上存在高维结构投影，均应当还原为高维结构的单位 1，才能正常训练；以及基点发生漂移现象**——复平面 i 幂周期（i, -1, -i, 1 单位圆）以原点 (0+0i) 为唯一基点，8 epochs 学会 acc 1.000；实数轴对称结构基点散落（neg{0} / reciprocal{±1} / inversion{1}）；基点漂移零样本完全崩（0/32），双锚需各自训练，显式穿折越等价样本不传递运算规则（锚绑定普遍成立）。经过剥离后，数轴的数值能够极为清晰地观测大量已知问题——据此做出课后习题的想法。

## 一、Pat 框架基本介绍

**PAT (Phase-Axis Theory) 是一个基于 Lean 4 形式化验证的构造性数学框架**, 出自框架奠基 (2026-08-12, R136–R153, 18 个 claim 全部经 `lake build` 验收、无 sorry)。框架回答的基础问题是: **自然数、π、素数、连续统、计算, 是从哪里来的?** 答案: 从方向声明出发, 经互锁构造出一切。

核心链条: (i) 方向必须按对称性成对一次性声明 (R136); (ii) 声明相同方向 ⟹ pat 链单射不坍缩 (R137); (iii) 相位关系未锁定 = pat0 自指循环坍缩 (R138); (iv) 相位-数值互锁矩阵——两组对称性 = 1 与 i 还原后的 1 (R139/R143); (v) 完整 pat1 = (相位, 距离) 联合声明, 构造⟷分解往返精确 (R140); (vi) pat n 有限离散 + 圆上单位根量化 (R141); (vii) 基点 0 视角的自然数↔单相位双映射 (发散/收敛) (R142); (viii) 0 与 1 = 对称对还原点, 素数圆/临界线圆 = 还原点的圆化 (R144/R145); (ix) 用 pat 构造所有数域, π = pat 链蜷曲半圈相位 (R146); (x) 因果与时间 = 成对互锁的对称方向 (R147); (xi) 互锁形式同构 = 4 相位两两互锁 + 无限同构外推 (R148/R149); (xii) 王氏可达周期与不可达无穷间相位锁定一致性定理 (R150); (xiii) 连续统 = pat 格点的闭包 (R151); (xiv) P vs NP: 有限域平凡 + 验证免费 + N = 相位锁定外推 (R152/R153)。

pat 的动力学只有一个动作——**发散/收敛互锁对** (R047/R147); 0 = 加法还原点, 1 = 乘法/相位还原点 (R144); 基点不是内生而是选择 (R062); 投影丢结构 (RulerLoss)。课后习题系列 (课后习题 I–XX + Pat0-1) 用这些已证定理对数学/物理经典问题做"pat 重新观测"——不是证明猜想, 而是把经典结构重述为 pat 几何, 全部新定理只锚框架定理, 不用外部引理。

## 二、剥离原因

### 2.1 主题剥离动机

主论文 (R136–R153) 对 P vs NP 只给侧写: R152 (有限域上 P = NP 平凡, 一切皆表) + R153 (N = 相位锁定外推)。该侧写需要剥离出来独立展开, 理由有三:

(i) **侧写需要剥离展开为详细论述**——主论文只钉死三个结论 (有限域平凡 + 验证免费 + N = 相位锁定外推), 中间机制 (验证 = 查表判等、witness ⟺ 表条目、模糊/结构对偶) 全部留白; 习题定位: 本题不是独立篇章, 是课后习题, 只有一个论点, 不枚举;

(ii) **它是"发散/收敛互锁对"在计算问题上的投影**——动力学只有一个动作 (R047/R147), P vs NP 是它投影到复杂性理论的经典结构 (验证便宜/求解贵 = 互锁对的两端, Aaronson [C12]、Fortnow [C10]; 计算 = 数学结构 = 一切皆表的表结构, Wigderson [C9]), 该投影的语义需要独立验证;

(iii) **直面经典复杂性理论需要独立语义**——经典 NP 定义 = "存在 witness + 多项式验证" (Cook [C1]、Levin [C2]、Goldreich [C8]), pat 语义把"验证"精确化为查表判等; 剥离观测须延续 R153 用户纠正精神 (全部新定理只锚框架定理, 不用外部引理), 并把"结构侧写"与"P≠NP 判定"严格区分。

### 2.2 剥离 (peel) 的框架定义

剥离 (peel) 是 pat 框架的相位操作 (R130): 自指结构 = 基点镜像 S_e(x) = 2e − x (对合, S_e(S_e x) = x, R128); **剥离 = 从对合提取位移场 Δ(x) = S_e(x) − x = 2(e − x)**——相位差显现 (方向), 方向声明 (R136) 成为剥离的必然产物; 未剥离 (对合黑箱) = 无净移动 = 坍缩到 pat 0 (R122/R134)。换基点观测下剥离平移不变 (P3): Δ_f(x + (f−e)) = Δ_e(x) (exercise_i_4, 三预言 P1 相位显现 / P2 自相似 / P3 换基点不变 全 PASS)。

**正式观测报告本身即一次剥离**: 从框架理论链的整体中剥离出单点观测对象 (本报告: P vs NP 的 pat 侧写), 剥离显现该主题的相位差 (独立论点: 模糊换速度/结构找回精确), 观测完成后再锚回框架 (全部新定理只锚框架定理)。剥离的是观测对象, 不是结论的独立性——观测不脱离框架。

### 2.3 完备逻辑框架: 投影恢复与基点恢复的必要性

按**任意阶任意元任意主客体逻辑完备性定理** (pre_pat/power_repr_success, 2026-08-14) 解释本报告的观测: 该定理断言——在解耦算子 D = Lift∘Exclude (R1 排除 a−a = 0 / R2 对消 (a−b)+(b−a) = 0 / R3 分层 L(D(P)) = L(P)+1) 作用于全部自指点之后, 任意阶/任意元/任意主客体配置的逻辑结构完备 (完美 OOD, 判定 1.000, 0 残差)。本报告的观测对象是这条定理的实例, 三个必要性如下:

1. **投影恢复的必要性**: 计算问题在发散/收敛互锁对上的投影 (验证表/存在性) = 高维结构在数轴上的降维投影 (R231: 投影有损)——压轴即自指之源 (同一位置承载多义结构); 不恢复投影 (加轴/全维度表达), 观测不完备 (一维恢复矩阵全无效应 0.994/0.996, 复平面加轴恢复 1.000)。NP 的 pat 语义 = 存在性经相位锁定外推给出, 不恢复投影 (表结构) 则 witness 存在性歧义, 求解与验证不可区分
2. **基点恢复的必要性**: 相位锁定外推的基点 0 是歧义源——基点漂移 (对称中心散落) 使同一数值承载不同位置语义 (基点恢复性实验: 基点归一化到 0, 数值减基点偏移, 位置唯一); 不恢复基点, 运算规则不跨基点传递 (跨基点零样本 0/32, I7k/I7l)。N = 相位锁定外推以基点 0 为锚, 基点漂移 ⟹ 外推方向歧义 (0/32 崩)
3. **剥离结果**: 本报告剥离本主题, 得到: **NP = 用模糊换速度、用结构找回精确; 有限域上 P = NP 平凡 (一切皆表)**——剥离 (peel, R130) 显现方向后, 观测锚回框架定理 (R150/R152/R153); 完备性验证: 验证 = 查表判等（双向） | 0 sorry（一次 build 通过；需 [DecidableEq E] 值域可判等） 。
4. **自指的位置**: witness 存在性 (N = 相位锁定外推——存在性自指: 是否存在 ⟺ 表条目)——自指 = 结构在自身处重合 (R231: 压轴即自指之源); 四步完备方法第 2 步 (定位自指) 要求定义链审计到自指点 (对合/递归/嵌套/循环), 解耦方式: 表判等双向 (RulerLookup: witness 存在 ⟺ 表条目存在)。
5. **解开自指的必要性**: 不解除自指, 基于该数域的各学科所有观测、分析都将受自指影响——同一位置承载多义结构, 歧义沿定义链传播 (残差指纹: 0.5 = 二义, 0.997 = 部分, 1.0 = 无)。**实验数据 (run_exp 配置驱动, token 训练, per_token_gen 逐 token OOD 泛化)**: 特别干净的单 token OOD 泛化 0/1 对比 (EXP-SYM-INV)——30 个 token 中 29 个 OOD 泛化 = 1.0, 唯一 inversion = 0.0 (per_token_gen 1/30 未达标); 未解除自指 (缺乏结构) ⟹ 该 token OOD = 0 (完全不可泛化); 解除自指 (结构充足/原生语法) ⟹ OOD = 1 (完全泛化, 嵌套 0.997 → 原生 1.000)。**对比时 token 的问题**: inversion (ℝ 上不对称: 0 奇异, 分数 1/2 不可表示) 仅 2 样本 → 缺乏结构 → 0.0; succ/translation (ℝ 对称, 38 样本) = 1.0; neg (反射, 低多样性) = 0.054 (单独/成对) / 1.0 (混合 ≥4 算符); 逐 token 收敛序 (EXP-SYM-FR-CURVE, 0/1 序列): multiplication (epoch 1) < power (3) < division (4) < inversion (5)。**实验结果位置**: `src/repo_v5/记录/paper_data/exp_sym_inv_results.md` (0/1 对比) / `exp_sym_token_observation.md` (逐 token 观测: succ 1.0, neg 0.054) / `exp_sym_fr_curve_results.md` (逐 token 0/1 收敛曲线) / `exp61_results.md` (单概念无对偶 0.092 → 加互逆对 0.927+) / `结论_准确语法解开自指与四步完备方法.md` (嵌套 0.997 → 原生 1.000)。**自指未解除 ⟹ OOD 0 (完全不可泛化); 解除 ⟹ OOD 1 (完全泛化)**, 与动机段"结构 token 不可泛化 / 直觉 token 可泛化"同源。

## 三、观测主体: P vs NP 的 pat 展开

### 3.1 观测对象与唯一论点

> 用框架已证定理（R136–R154），把 P vs NP（R152 框架侧写 + R153 N = 相位锁定外推）展开为 pat 视角下的详细论述，并在 Lean 中形式化验证。要求：全部新定理只锚框架定理，不用外部引理。

> **用户原话 (2026-08-13, R157 user_original_words ③, 原封不动保存)**: "不要试图过度枚举，没意义。这个框架下需要的是用模糊换速度，用结构找回精确。"
>
> **本题唯一论点：NP 的 pat 语义 = 用模糊换速度，用结构找回精确。**（论点即用户原话，未经改写）

- **模糊** = N 的存在性：witness 的猜测不穷举——存在性由相位锁定外推给出（R150 王氏定理），不搜遍候选。
- **结构** = 验证表：有限域函数 = 预计算表（RulerLookup/R057 一切皆表），表是结构；witness 存在 ⟺ 表条目存在（双向）——模糊的猜测经表判等还原为精确答案。
- **有限域上 P = NP 平凡**（R152）：结构已完备（表全量），模糊不必要——求解与验证都 O(1)。

### 3.2 观测过程

**① 用结构找回精确: 验证 = 查表判等 (RulerLookup/RulerRevLookup)**

★核心：验证不重算，只判等——y = f x ⟺ (x, y) ∈ 表，双向。

- **表 = 结构**（RulerLookup function_is_table / R057）：有限域上任意函数 f = 预计算表 {(x, f x)}。表是"把计算凝固成位置"的结构。对照：计算 = 数学结构的纲领（Wigderson [C9]）、算法 = 表/结构的经典实践（Knuth [C20]）。
- **验证 = 查表判等**（R152 ② 展开）：验证 y 是否是 f x 的答案 = 检查 (x, y) 是否在表中——双向等价：y = f x ⟹ 表条目（lookup_exists：表全量），表条目 ⟹ y = f x（lookup_correct：表值 = 函数值）。对照：验证便宜/求解贵的经典不对称直觉（Aaronson [C12]、Fortnow [C10]）——在本框架中，验证 = 查表判等，求解 = 同一条目的前向查询（R152 有限域平凡）。
- **这是"找回精确"**：模糊的候选 y 经"表中判等"这一步还原为精确的真假——结构（表）是精确的锚。对照：交互证明中验证者的角色（Goldwasser–Micali–Rackoff [C15]）；信息 = 结构、可逆计算 = 信息保持（Shannon [M10]、Landauer [M11]、Bennett [M12]）。

**② 模糊与结构等价: witness ⟺ 表条目 (双向, 强化 R153)**

★核心：模糊的 witness 猜测与结构的表条目完全等价——双向。

- **R153 只给了单向**：witness 存在 ⟹ 表条目存在（np_witness_in_table）。
- **反向由表结构封死**：表条目 (w, true) ∈ 表 ⟹ true = V x w（lookup_correct：表值 = 函数值）⟹ V x w = true。
- **双向 = 模糊/结构等价**：∃ witness（模糊）⟺ ∃ 表条目（结构）——猜测的"存在"和结构的"存在"是同一个存在。模糊没有损失，因为它和结构一一对应。对照：NP 存在性 = 验证表条目的标准语义（Cook [C1]、Levin [C2]、Goldreich [C8]）——经典复杂性理论以"存在 witness + 多项式验证"定义 NP，本框架把验证精确化为查表判等。

**③ ★NP 的模糊/结构对偶 (本题核心定理)**

★核心：NP 的 pat 语义 = 模糊存在性 ∧ 结构判等同时成立。

- **模糊换速度**：∃ w, V x w = true——witness 的存在性不穷举，由相位锁定外推保证（R150，见④）。对照：平均情形/随机化"用概率换效率"的经典路线（Rabin [C14]、Impagliazzo [C13]）——本框架的模糊是相位层的，非概率层的。
- **结构找回精确**：∀ w, V x w = true ⟺ (w, true) ∈ 表——任何候选都能经表判等得到精确真值。对照：去随机化（用结构消除概率，Vadhan [C19]）；可逆计算（用结构保持信息，Bennett [M12]）——都是"结构找回精确"的经典实例。
- **对偶定理**：模糊存在性 ⟹ 结构存在性 ∧ 逐点判等——猜测与判等同一互锁对（R147：求解/验证 = 发散/收敛互锁对），发散端给出存在性，收敛端给出精确性。对照：几何相位 = 相位锁定（Berry [Q1]、Aharonov–Bohm [Q4]）——相位差是物理实在，不是计算伪影。

**④ 全景: 模糊 (N) + 结构 (验证) + 锁定 (P)**

★核心：P vs NP 在 pat 视角 = 三个结构位——N 是相位锁定外推（模糊），验证是查表判等（结构），P 是锁定方向唯一链（无模糊）。

- **N = 相位锁定外推**（R150 王氏定理 / R153 ③）：任意未锁定相位 θ 被 pat 格点任意精度统一（∀ ε, ∃ 格点 |θ - x| ≤ ε）——非确定性的存在性由相位锁定外推给出，不穷举。**这是模糊换速度的存在性来源**。对照：凝聚数学（Scholze [M21]）以相似方式用稠密格点统一连续结构。
- **验证 = 查表判等**（①）：∀ w, V x w = true ⟺ 表条目——结构找回精确。对照：Lean 形式化 = 当代"用结构找回精确"的工程（de Moura [M28]、mathlib [M29]、Buzzard [M30]、Avigad [M31]、Hales [M23]）——本习题的 Lean 验收即同一工程的一个实例。
- **P = 锁定方向唯一链**（R153 ① / R050 机制）：x ↦ x + d 单射——确定性没有模糊。
- **有限域上 P = NP 平凡**（R152）：表全量 ⟹ 结构已完备 ⟹ 模糊不必要——求解与验证都 O(1)，多项式与常数无别。对照：可计算性 = 形式结构边界的经典结果（Gödel [M1]、Turing [M2]、Church [M3]）——有限域上一切皆表 = 结构完备即无模糊。
- **诚实边界**：以上全部为结构侧写，非 P≠NP 判定（规模增长下界不在框架内，R152 边界延续；经典复杂性层级见 Hartmanis–Stearns [C4]、Sipser [C5]、Arora–Barak [C7]）。
