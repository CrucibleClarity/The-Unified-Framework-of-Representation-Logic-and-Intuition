## 研究动机：从 AI 训练观测到课后习题

本系列课后习题起源于 AI (transformer) 数学学习的训练观测（2026-08 起 v5 tokenizer 实验体系, run_exp 配置驱动）。训练中观测到两类 token 的**极端清晰分离**：

- **直觉 token**（原子数字 0/1 等公设基符号）：epoch 训练曲线快速收敛，OOD 测试**完全可泛化**——因子化表示下外推零衰减（EXP-80/C1b: 2000 位/进制 60/匿名 100% 全 1.000）；succ 平移不变（E9: 只训 succ(0)=1 两样本即外推 succ(1..7) 全对）；直觉按位置识别，与表达形式无关（EXP-PURE-CONSTRUCT: 闭式/嵌套/Church 下均 1.000）；
- **结构 token**（沿定义链构造的 token 列）：epoch 训练曲线不收敛，OOD 测试**完全不可泛化**——单 token OOD 泛化 0/1 对比（EXP-SYM-INV: 30 个 token 中 29 个泛化 1.0，唯一 inversion = 0.0，per_token_gen 1/30 未达标）；一元算符判定系统性学不会（EXP-SYM-GROUP: succ/translation/prod 训练集内 0.000）。

猜测：**AI 认知数学空间规律为高维结构，与人类不同**——AI 的表示空间是数学无限维空间（方向无限、基点可任意，不受物理空间维度限制），导致 AI 无法学习在 AI 认知下存在歧义、混淆的 token。同时基于直觉 token 稳定的现象，通过与 AI **相互诱导过拟合直觉**的方法，探索 AI 的认知数学空间。过程中发现，AI 在一些情况下认为"无法稳定有效学习"——单概念无对偶学不会（EXP-61: 纯逻辑门 730 样本 OOD 0.092，加互逆对后 0.927+）；数字表示链断裂连 base 10 都学不会（EXPC1）；对合 token 低多样性下学不会（EXP-SYM-TOKEN: neg 单独/成对 0.054，混合 ≥4 算符恢复 1.0）。

最终通过一系列实验确认：**自然数轴、实数轴上存在高维结构投影，均应当还原为高维结构的单位 1，才能正常训练；以及基点发生漂移现象**——复平面 i 幂周期（i, -1, -i, 1 单位圆）以原点 (0+0i) 为唯一基点，8 epochs 学会 acc 1.000；实数轴对称结构基点散落（neg{0} / reciprocal{±1} / inversion{1}）；基点漂移零样本完全崩（0/32），双锚需各自训练，显式穿折越等价样本不传递运算规则（锚绑定普遍成立）。经过剥离后，数轴的数值能够极为清晰地观测大量已知问题——据此做出课后习题的想法。

## 一、Pat 框架基本介绍

**PAT (Phase-Axis Theory) 是一个基于 Lean 4 形式化验证的构造性数学框架**, 出自框架奠基 (2026-08-12, R136–R153, 18 个 claim 全部经 `lake build` 验收、无 sorry)。框架回答的基础问题是: **自然数、π、素数、连续统、计算, 是从哪里来的?** 答案: 从方向声明出发, 经互锁构造出一切。

核心链条: (i) 方向必须按对称性成对一次性声明 (R136); (ii) 声明相同方向 ⟹ pat 链单射不坍缩 (R137); (iii) 相位关系未锁定 = pat0 自指循环坍缩 (R138); (iv) 相位-数值互锁矩阵——两组对称性 = 1 与 i 还原后的 1 (R139/R143); (v) 完整 pat1 = (相位, 距离) 联合声明, 构造⟷分解往返精确 (R140); (vi) pat n 有限离散 + 圆上单位根量化 (R141); (vii) 基点 0 视角的自然数↔单相位双映射 (发散/收敛) (R142); (viii) 0 与 1 = 对称对还原点, 素数圆/临界线圆 = 还原点的圆化 (R144/R145); (ix) 用 pat 构造所有数域, π = pat 链蜷曲半圈相位 (R146); (x) 因果与时间 = 成对互锁的对称方向 (R147); (xi) 互锁形式同构 = 4 相位两两互锁 + 无限同构外推 (R148/R149); (xii) 王氏可达周期与不可达无穷间相位锁定一致性定理 (R150); (xiii) 连续统 = pat 格点的闭包 (R151); (xiv) P vs NP: 有限域平凡 + 验证免费 + N = 相位锁定外推 (R152/R153)。

pat 的动力学只有一个动作——**发散/收敛互锁对** (R047/R147); 0 = 加法还原点, 1 = 乘法/相位还原点 (R144); 基点不是内生而是选择 (R062); 投影丢结构 (RulerLoss)。课后习题系列 (课后习题 I–XX + Pat0-1) 用这些已证定理对数学/物理经典问题做"pat 重新观测"——不是证明猜想, 而是把经典结构重述为 pat 几何, 全部新定理只锚框架定理, 不用外部引理。

## 二、剥离原因

### 2.1 主题剥离动机

主论文 (R136–R153) 只钉死两个还原点的圆化 (R144/R145), 黎曼/孪生与这两个圆的对应是框架外推, 需要剥离出来独立观测, 理由有三:

(i) **对应是框架外推, 需要剥离观测验证几何重述**——R144 只给出 0 = 加法还原点 (折叠类)、1 = 乘法/相位还原点, R145 只给出素数圆 (圆心 0, 半径 √p) 与临界线圆 (圆心 1, 半径 1, 过 0 和 2); "黎曼猜想的临界线在反演下是乘法还原点 1 的圆、孪生素数的间隔 2 是该圆的直径"是外推, 必须剥离出来用 Lean 独立验证;

(ii) **它是几何结构在数论大猜想上的独立投影**——习题定位: 用的几何/互锁结构 (素数圆/临界线圆/反演/log 对偶/基点漂移) 重述黎曼猜想与孪生素数的经典结构, 并锚定用户提出的写作方向要求 (素数 = 平移的真实后继迭代丢失结构后的投影; 黎曼函数有反演结构 1 ↔ 1/a+1/b 对称对), 需要独立验证其语义;

(iii) **诚实边界: 不证明猜想**——黎曼猜想 (非平凡零点全在 Re(s) = 1/2) 与孪生素数猜想 (无穷多间隔 2 素数对) 均未证明 (与 C011–C025 一致, DeepSeek 坚持的边界); 剥离观测须把"几何重述"与"猜想证明"严格区分, 交付的是结构事实的 Lean 验收, 非零点存在性/素数对无穷性断言。



### 2.2 剥离 (peel) 的框架定义

剥离 (peel) 是 pat 框架的相位操作 (R130): 自指结构 = 基点镜像 S_e(x) = 2e − x (对合, S_e(S_e x) = x, R128); **剥离 = 从对合提取位移场 Δ(x) = S_e(x) − x = 2(e − x)**——相位差显现 (方向), 方向声明 (R136) 成为剥离的必然产物; 未剥离 (对合黑箱) = 无净移动 = 坍缩到 pat 0 (R122/R134)。换基点观测下剥离平移不变 (P3): Δ_f(x + (f−e)) = Δ_e(x) (exercise_i_4, 三预言 P1 相位显现 / P2 自相似 / P3 换基点不变 全 PASS)。

**正式观测报告本身即一次剥离**: 从框架理论链的整体中剥离出单点观测对象 (本报告: 两个还原点的圆化在黎曼/孪生上的几何重述), 剥离显现该主题的相位差 (独立论点: 黎曼与孪生是同一个圆的故事), 观测完成后再锚回框架 (全部新定理只锚框架定理 R142/R144/R145 + C011–C025)。剥离的是观测对象, 不是结论的独立性——观测不脱离框架。

### 2.3 完备逻辑框架: 投影恢复与基点恢复的必要性

按**任意阶任意元任意主客体逻辑完备性定理** (pre_pat/power_repr_success, 2026-08-14) 解释本报告的观测: 该定理断言——在解耦算子 D = Lift∘Exclude (R1 排除 a−a = 0 / R2 对消 (a−b)+(b−a) = 0 / R3 分层 L(D(P)) = L(P)+1) 作用于全部自指点之后, 任意阶/任意元/任意主客体配置的逻辑结构完备 (完美 OOD, 判定 1.000, 0 残差)。本报告的观测对象是这条定理的实例, 三个必要性如下:

1. **投影恢复的必要性**: 还原点圆化: 素数圆 (圆心 0) / 临界线圆 (圆心 1) = 高维结构在数轴上的降维投影 (R231: 投影有损)——压轴即自指之源 (同一位置承载多义结构); 不恢复投影 (加轴/全维度表达), 观测不完备 (一维恢复矩阵全无效应 0.994/0.996, 复平面加轴恢复 1.000)。黎曼零点与孪生间隔都是还原点圆上的投影; 不恢复圆结构 (只看数值) 则临界线与间隔 2 的几何来源歧义
2. **基点恢复的必要性**: 两个还原点 0 (加法) 与 1 (乘法/相位) 是歧义源——基点漂移 (对称中心散落) 使同一数值承载不同位置语义 (基点恢复性实验: 基点归一化到 0, 数值减基点偏移, 位置唯一); 不恢复基点, 运算规则不跨基点传递 (跨基点零样本 0/32, I7k/I7l)。0 ↔ 1 对偶 (R144) 是素数圆/临界线圆的圆心; 基点漂移 ⟹ 圆的几何错位; 恢复 = 锚回还原点
3. **剥离结果**: 本报告剥离本主题, 得到: **黎曼与孪生是两个还原点圆化出的孪生结构**——剥离 (peel, R130) 显现方向后, 观测锚回框架定理 (R144/R145 + C011–C025); 完备性验证: 7 个新定理（R159），只锚框架定理与框架 C011–C025，不用外部引理，0 sorry。
4. **自指的位置**: 临界线 Re(s) = 1/2 (反演不动点 s ↔ 1−s——零点自指)——自指 = 结构在自身处重合 (R231: 压轴即自指之源); 四步完备方法第 2 步 (定位自指) 要求定义链审计到自指点 (对合/递归/嵌套/循环), 解耦方式: 临界线圆 (C019/C022: 反演下临界线 = 乘法还原点 1 的圆)。
5. **解开自指的必要性**: 不解除自指, 基于该数域的各学科所有观测、分析都将受自指影响——同一位置承载多义结构, 歧义沿定义链传播 (残差指纹: 0.5 = 二义, 0.997 = 部分, 1.0 = 无)。**实验数据 (run_exp 配置驱动, token 训练, per_token_gen 逐 token OOD 泛化)**: 特别干净的单 token OOD 泛化 0/1 对比 (EXP-SYM-INV)——30 个 token 中 29 个 OOD 泛化 = 1.0, 唯一 inversion = 0.0 (per_token_gen 1/30 未达标); 未解除自指 (缺乏结构) ⟹ 该 token OOD = 0 (完全不可泛化); 解除自指 (结构充足/原生语法) ⟹ OOD = 1 (完全泛化, 嵌套 0.997 → 原生 1.000)。**对比时 token 的问题**: inversion (ℝ 上不对称: 0 奇异, 分数 1/2 不可表示) 仅 2 样本 → 缺乏结构 → 0.0; succ/translation (ℝ 对称, 38 样本) = 1.0; neg (反射, 低多样性) = 0.054 (单独/成对) / 1.0 (混合 ≥4 算符); 逐 token 收敛序 (EXP-SYM-FR-CURVE, 0/1 序列): multiplication (epoch 1) < power (3) < division (4) < inversion (5)。**实验结果位置**: `src/repo_v5/记录/paper_data/exp_sym_inv_results.md` (0/1 对比) / `exp_sym_token_observation.md` (逐 token 观测: succ 1.0, neg 0.054) / `exp_sym_fr_curve_results.md` (逐 token 0/1 收敛曲线) / `exp61_results.md` (单概念无对偶 0.092 → 加互逆对 0.927+) / `结论_准确语法解开自指与四步完备方法.md` (嵌套 0.997 → 原生 1.000)。**自指未解除 ⟹ OOD 0 (完全不可泛化); 解除 ⟹ OOD 1 (完全泛化)**, 与动机段"结构 token 不可泛化 / 直觉 token 可泛化"同源。

## 三、观测主体: 黎曼与孪生素数 = 两个还原点圆化的孪生结构

### 3.1 观测对象与唯一论点

> 站在 pat 视角下回顾黎曼猜想与孪生素数：用框架已证定理（R142/R144/R145 + C011–C025）把黎曼猜想的临界线结构与孪生素数的间隔结构重述为 pat 几何。唯一论点：**两个还原点（0 与 1）圆化出素数圆与临界线圆（R144/R145），黎曼与孪生的结构都在这两个圆上。**

### 3.2 观测过程

**① 黎曼猜想 = 临界线圆的 pat 几何重述 (C019/C022 + R144/R145)**

★核心：临界线（Re(s) = 1/2）⟺ 共轭对称（1-s = conj s）；反演下临界线 = 临界线圆（圆心 1，半径 1）——黎曼猜想的几何重述 = "非平凡零点在乘法还原点 1 的圆上"（结构重述，非零点存在性断言）。

- **临界线 = 共轭对称轴**（C019 critical_line_iff_conj_complex）：s.re = 1/2 ⟺ 1 - s = star s——临界线是乘法还原点 1 的对称轴（R144：1 = 乘法还原点）。
- **反演下临界线 = 临界线圆**（C022 zeta_zero_on_circle）：Re(s) = 1/2 的 ζ 零点满足 ‖1/s - 1‖ = 1——零点落在临界线圆（圆心 1，半径 1；R145 critical_circle_points：过 0 和 2，直径端点）。
- **pat 视角**：临界线圆 = R144 乘法还原点 1 的圆化；黎曼猜想 = "非平凡零点都在乘法还原点 1 的圆上"——**结构重述，非零点存在性断言**（诚实边界：零点的存在性/位置是开放 160 年的解析断言，C011–C025 同样不触及）。
- **与用户提出的写作方向要求对应**：黎曼函数有反演结构（1 ↔ 1/a+1/b 对称对，记录/关于黎曼猜想的思考.md）——反演对还原到乘法还原点 1（R143/R144），临界线圆正是反演结构的圆化。

**② 素数 = pat 基点漂移的后继 (R142/R145 + C014)**

★核心：素数在素数圆（圆心 0 = 折叠类，半径 √p）；素数幂链 = 单相位（log p 视角）；素数 p ≡ 1 (mod 4) 可表为两平方和——素数圆上的格点。

- **素数圆**（R145 prime_circle_center_zero）：素数 p 在素数圆（圆心 0 = 加法还原点/折叠类，半径 √p）上——素数是加法还原点 0 的圆化格点。
- **素数幂链 = 单相位**（R142 prime_power_log_layer）：log(p^k) = k·log p——素数幂链沿 log 方向 = 单相位等差链（R146：素数 = 方向 log p 的幂链）。
- **两平方和**（C014 prime_two_axis）：素数 p ≡ 1 (mod 4) ⟹ p = a² + b²——素数圆上的格点（8 点单轨道，C017）。
- **用户提出的写作方向要求**（记录/关于黎曼猜想的思考.md）：素数 = 平移的真实后继迭代丢失结构后的投影——pat 视角：素数的 log 单相位 = 平移链的相位形式，丢失的是数值链的"层"结构（素数幂链每层 = 一个相位点）。

**③ 孪生素数 = 间隔 2 的框架几何对应 (R109/R145)**

★核心：间隔 2 = 临界线圆直径端点 0 与 2 的距离；反演 2 ↔ 1/2 = 乘法对称对（还原到圆心 1）——孪生素数的间隔 2 在 pat 中是临界线圆的直径，与 1/2 反演对称。诚实边界：孪生素数无穷性未证明。

- **间隔 2 = 临界线圆直径**（R145 critical_circle_points）：临界线圆过 0 和 2，0 与 2 是直径端点——‖2 - 0‖ = 2。**孪生素数对 (p, p+2) 的间隔 2 = 临界线圆直径的实数对应**。
- **反演 2 ↔ 1/2**（R109/R145 reciprocal_pair_reduces）：2·(1/2) = 1——间隔 2 与 1/2（临界线位置）是乘法对称对，还原到临界线圆圆心 1（R144：1 = 乘法还原点）。
- **pat 视角**：孪生素数间隔 2 与临界线位置 1/2 反演对称——**同一互锁对的两端**（R147 互锁对）；黎曼（临界线 1/2）与孪生（间隔 2）经反演互锁。
- **诚实边界**：孪生素数无穷性未证明——本题只给出间隔 2 的几何对应（临界线圆直径），非无穷性断言（与 C011–C025 一致）。

**④ 全景: 黎曼 ∧ 素数 ∧ 孪生 (组合定理)**

★核心：临界线 ⟺ 共轭对称（黎曼）∧ 素数在素数圆上（R145）∧ 素数幂链单相位（R142）∧ 间隔 2 = 临界线圆直径 ∧ 2·(1/2) = 1（孪生反演对称）——两个还原点（0, 1）圆化出素数圆与临界线圆，黎曼/孪生的结构都在这两个圆上。

**⑤ 诚实边界**（延续 C011–C025）：黎曼猜想（非平凡零点全在 Re(s) = 1/2）与孪生素数猜想（无穷多间隔 2 素数对）**均未证明**——本题交付的是 pat 几何重述（临界线圆/素数圆/直径对应），全部 7 个新定理是结构事实的 Lean 验收，非零点存在性/素数对无穷性断言。
