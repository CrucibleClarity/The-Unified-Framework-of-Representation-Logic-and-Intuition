## 零、总论：为什么黎曼与孪生在 pat 视角下是同一个故事

 R144 钉死两个还原点：0 = 加法还原点（折叠类），1 = 乘法/相位还原点。R145 把这两个还原点圆化：

- **素数圆**（圆心 0，半径 √p）= 加法还原点 0 的圆化；
- **临界线圆**（圆心 1，半径 1，过 0 和 2）= 乘法还原点 1 的圆化。

黎曼猜想与孪生素数在 pat 视角下是**这两个圆的孪生结构**：

- **黎曼**：非平凡零点的临界线（Re(s) = 1/2）在反演下 = 临界线圆（C019/C022）——黎曼猜想的几何重述 = "零点在乘法还原点 1 的圆上"。
- **孪生**：间隔 2 = 临界线圆直径端点 0 与 2 的距离；反演 2 ↔ 1/2 = 乘法对称对（R109/R145）——孪生素数的间隔 2 与临界线位置 1/2 反演对称。

用户洞察（记录/关于黎曼猜想的思考.md）：素数 = 平移的真实后继迭代丢失结构后的投影；黎曼函数有反演结构（1 ↔ 1/a+1/b 对称对）。本题把这些洞察锚到框架定理。

## 一、黎曼猜想 = 临界线圆的 pat 几何重述（C019/C022 + R144/R145）

**★核心：临界线（Re(s) = 1/2）⟺ 共轭对称（1-s = conj s）；反演下临界线 = 临界线圆（圆心 1，半径 1）——黎曼猜想的几何重述 = "非平凡零点在乘法还原点 1 的圆上"（结构重述，非零点存在性断言）。**

### 论证

1. **临界线 = 共轭对称轴**（C019 critical_line_iff_conj_complex）：s.re = 1/2 ⟺ 1 - s = star s——临界线是乘法还原点 1 的对称轴（R144：1 = 乘法还原点）。
2. **反演下临界线 = 临界线圆**（C022 zeta_zero_on_circle）：Re(s) = 1/2 的 ζ 零点满足 ‖1/s - 1‖ = 1——零点落在临界线圆（圆心 1，半径 1；R145 critical_circle_points：过 0 和 2，直径端点）。
3. **pat 视角**：临界线圆 = R144 乘法还原点 1 的圆化；黎曼猜想 = "非平凡零点都在乘法还原点 1 的圆上"——**结构重述，非零点存在性断言**（诚实边界：零点的存在性/位置是开放 160 年的解析断言，C011–C025 同样不触及）。
4. **与用户洞察对应**：黎曼函数有反演结构（1 ↔ 1/a+1/b 对称对，记录/关于黎曼猜想的思考.md）——反演对还原到乘法还原点 1（R143/R144），临界线圆正是反演结构的圆化。

### 形式化（PatRiemannTwinPrimes.lean，2 定理）

- `critical_line_pat_circle`：s.re = 1/2 ⟺ 1 - s = star s——临界线 = 共轭对称轴（C019）。
- `zero_on_pat_circle`：Re(s) = 1/2 的 ζ 零点 ⟹ ‖1/s - 1‖ = 1——零点落在临界线圆上（C022）。

**验证**：0 sorry。锚定 ZetaEulerProduct.critical_line_iff_conj_complex / zeta_zero_on_circle。

## 二、素数 = pat 基点漂移的后继（R142/R145 + C014）

**★核心：素数在素数圆（圆心 0 = 折叠类，半径 √p）；素数幂链 = 单相位（log p 视角）；素数 p ≡ 1 (mod 4) 可表为两平方和——素数圆上的格点。用户洞察：素数 = 平移的真实后继迭代丢失结构后的投影。**

### 论证

1. **素数圆**（R145 prime_circle_center_zero）：素数 p 在素数圆（圆心 0 = 加法还原点/折叠类，半径 √p）上——素数是加法还原点 0 的圆化格点。
2. **素数幂链 = 单相位**（R142 prime_power_log_layer）：log(p^k) = k·log p——素数幂链沿 log 方向 = 单相位等差链（R146：素数 = 方向 log p 的幂链）。
3. **两平方和**（C014 prime_two_axis）：素数 p ≡ 1 (mod 4) ⟹ p = a² + b²——素数圆上的格点（8 点单轨道，C017）。
4. **用户洞察**（记录/关于黎曼猜想的思考.md）：素数 = 平移的真实后继迭代丢失结构后的投影（"素数会不会也是平移的真实后继迭代，只是丢失了某些结构"）——pat 视角：素数的 log 单相位 = 平移链的相位形式，丢失的是数值链的"层"结构（素数幂链每层 = 一个相位点）。

### 形式化（PatRiemannTwinPrimes.lean，2 定理）

- `prime_on_pat_circle`：‖√p·exp(θ·I) - 0‖ = √p——素数在素数圆上（R145）。
- `prime_log_monophase`：log(p^k) = k·log p——素数幂链 = 单相位（R142）。

**验证**：0 sorry。锚定 CriticalPrimeCircles.prime_circle_center_zero / Real.log_pow。

## 三、孪生素数 = 间隔 2 的框架几何对应（R109/R145）

**★核心：间隔 2 = 临界线圆直径端点 0 与 2 的距离；反演 2 ↔ 1/2 = 乘法对称对（还原到圆心 1）——孪生素数的间隔 2 在 pat 中是临界线圆的直径，与 1/2 反演对称。诚实边界：孪生素数无穷性未证明。**

### 论证

1. **间隔 2 = 临界线圆直径**（R145 critical_circle_points）：临界线圆过 0 和 2，0 与 2 是直径端点——‖2 - 0‖ = 2。**孪生素数对 (p, p+2) 的间隔 2 = 临界线圆直径的实数对应**。
2. **反演 2 ↔ 1/2**（R109/R145 reciprocal_pair_reduces）：2·(1/2) = 1——间隔 2 与 1/2（临界线位置）是乘法对称对，还原到临界线圆圆心 1（R144：1 = 乘法还原点）。
3. **pat 视角**：孪生素数间隔 2 与临界线位置 1/2 反演对称——**同一互锁对的两端**（R147 互锁对）；黎曼（临界线 1/2）与孪生（间隔 2）经反演互锁。
4. **诚实边界**：孪生素数无穷性未证明——本题只给出间隔 2 的几何对应（临界线圆直径），非无穷性断言（与 C011–C025 一致）。

### 形式化（PatRiemannTwinPrimes.lean，2 定理）

- `twin_gap_is_circle_diameter`：‖2 - 0‖ = 2——间隔 2 = 临界线圆直径（R145）。
- `twin_gap_inversion_symmetry`：2·(1/2) = 1——间隔 2 与 1/2 反演对称（R109/R145）。

**验证**：0 sorry。教训：`2*(1/2)` 在 ℝ 上需显式类型注解（否则被推断为 ℕ）。
