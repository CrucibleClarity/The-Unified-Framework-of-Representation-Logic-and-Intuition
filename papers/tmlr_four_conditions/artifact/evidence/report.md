> 配置: dim=64, layers=2, epochs=60, lr=1e-3, seeds {0,1,2} (见 experiments/configs.json)。

## 二、两极对比 (核心观测)

```
训练 acc:  1.000 (全部, 表示内记忆/统计完备)
OOD ①b:   0/32   —— 同基点换记法 (succ_a → succ_b) 零样本全崩
OOD ②:    32/32  —— 加等价对比题 (等价声明桥接) 后全过
```

- **0 极** (失败态): 记法绑定 — 训练直觉只认 succ_a 的序列形式,
  succ_b 是"同一个 succ 的另一种写法", 零样本不迁移。
- **1 极** (成功态): 等价声明 (对比题: succ_a 链 n = succ_b 链 n)
  作为显式桥接样本进入训练, 0/32 → 32/32。
- 两极都看到才能宣称对比成功 (两极对比纪律 I7ag)。

## 三、token 级报告 (崩点形态)

①b 的 0/32: 崩在表示差异的第一个 token — succ_a 与 succ_b 是同一
位置的记法差异, 输入头仍可过 (32/32 输入重建), 崩点 = 记法分叉位置。
聚合 acc 掩盖崩点; token 级暴露直觉路径失效位置 (跨表示剥离 I7n)。

## 四、判定口径

- 判定: 完整序列逐 token 重建全对 (末尾真值判定可信);
- 位置级 acc 不可信 (本文全部 32/32 与 0/32 均为完整序列判定)。

## 五、结论

1. **训练直觉 = 表示绑定的统计**: 1.000 训练 acc 不传递到未训练记法;
   OOD 1.0 只证明"该表示下统计可外推", 与结构无关 (I7n 彻底结论)。
2. **等价声明是桥接工具**: 对比题 (锚定错题无关) 使同基点两种记法
   互译 — 声明让信息指向准确结构。
3. **可复现**: 三次独立运行 (原环境 ×2 + 自包含包) 逐 seed 一致,
   无随机性漂移 — 实证基础稳固。
